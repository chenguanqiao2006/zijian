# 规格卡 1：高量柱

## 元数据

- signal_name：高量柱
- signal_id：high_volume
- spec_version：1.0
- source_book：《量柱擒涨停》（第4版）
- source_chapter：第二单元 量柱擒涨停的六个元素，第8-13章
- effective_confirmation：当日收盘后确认（T日）
- dependencies：无（基础信号）

## 1. 自然语言定义

高量柱是指某一阶段内成交量最高的量柱。量化标准为：当日成交量为最近10个交易日内的最高值，或当日成交量超前3日平均成交量50%以上。高量柱反映市场活跃度的极端状态，是资金大幅介入或出逃的信号。

## 2. 输入数据

| 变量名 | 数据含义 | 数据类型 | 数据来源 |
|:---|:---|:---|:---|
| V[t] | 当日成交量 | float > 0 | 行情数据源（前复权） |
| V[t-1], V[t-2], ..., V[t-9] | 前1至前9日成交量 | float > 0 | 行情数据源（前复权） |
| C[t] | 当日收盘价 | float > 0 | 行情数据源（前复权） |

## 3. 精确计算公式

判定标准A（阶段最高量）：

    V[t] = max(V[t-9], V[t-8], ..., V[t])
    即：V[t] = HHV(V, 10)

判定标准B（超前3日均量50%）：

    V[t] > (V[t-1] + V[t-2] + V[t-3]) / 3 × 1.5

总判定：

    高量柱 = 标准A OR 标准B

## 4. 判定条件（布尔表达式）

    high_volume[t] = (V[t] == HHV(V, 10)) OR (V[t] > (V[t-1] + V[t-2] + V[t-3]) / 3 * 1.5)

其中 HHV(V, 10) 表示最近10日（含当日）成交量的最高值。

## 5. 边界情况

| 情况 | 处理方式 |
|:---|:---|
| V[t-1] == 0（停牌后首日） | 跳过该日，不判定高量柱；需至少3个有效交易日数据 |
| 新股上市首日 | 不判定（无足够历史数据，需上市满10个交易日后启用） |
| 除权除息日 | 必须使用前复权成交量数据；若使用未复权数据，信号无效 |
| 数据异常（负数、空值） | 该日数据视为无效，跳过；连续无效数据超过3日则信号暂停 |
| 上市不足10日 | 标准A不可用，仅标准B可用（需至少3个有效交易日） |

## 6. 输出格式（JSON）

    {
      "signal_id": "high_volume",
      "signal_name": "高量柱",
      "date": "2026-10-05",
      "is_signal": true,
      "match_criteria": "A",
      "values": {
        "v_t": 125000000,
        "hhv_10": 125000000,
        "ma3": 60000000,
        "ratio_to_ma3": 2.08
      },
      "confirmation_date": "2026-10-05",
      "data_quality": "valid"
    }

## 7. 确认日定义（零未来函数）

高量柱为当日确认信号，确认日为T日收盘后。仅使用V[t]及V[t-1]至V[t-9]的数据，不使用任何未来数据。无未来函数。

## 8. 测试用例

测试用例1（标准A命中）：

- 输入：V[t-9..t-1] = [50, 55, 52, 58, 60, 57, 62, 59, 61]（单位：万股），V[t] = 95
- 计算：HHV(V,10) = 95，V[t] == HHV → 标准A命中
- 预期输出：is_signal = true, match_criteria = "A"

测试用例2（标准B命中）：

- 输入：V[t-3]=40, V[t-2]=42, V[t-1]=38, V[t]=70
- 计算：MA3 = (40+42+38)/3 = 40，V[t]/MA3 = 1.75 > 1.5 → 标准B命中
- 预期输出：is_signal = true, match_criteria = "B"

测试用例3（未命中）：

- 输入：V[t-3]=50, V[t-2]=52, V[t-1]=48, V[t]=55，且最近10日最高量为80
- 计算：HHV(V,10)=80 ≠ 55；MA3=50，V[t]/MA3=1.1 < 1.5 → 均不命中
- 预期输出：is_signal = false

## 9. 依赖关系说明

高量柱为基础信号，无前置依赖。高量柱是以下信号的输入或组成部分：

- 黄金柱（基柱候选）
- 将军柱（基柱候选）
- 倍量柱（可能同时为高量柱）

## 10. 参数适配说明

| 项目 | 内容 |
|:---|:---|
| 原著初版参数 | 高量柱为“某一阶段的最高量柱”，未明确量化周期和阈值 |
| 最新修订版（2021年第4版）是否更新 | 经检索《量柱擒涨停》第4版，未发现对高量柱参数的明确更新，沿用“阶段最高量柱”的定性定义 |
| 其他权威理论补充 | 同花顺指标平台公开公式（2016年上传，2021年仍可访问），第三方公开公式，仅作参考，采用 V=HHV(V,10) 作为高量柱判定标准。本规格采用双标准OR逻辑，兼顾“阶段最高”与“相对放量”两种定义 |
| 当前市场环境适用性 | 10日周期和50%阈值在大部分个股上仍适用。整理者分析，非权威来源：2015年以后A股市场成交量结构发生变化（量化交易占比提升、涨跌停制度调整），对于日均成交额低于5000万元的低流动性个股，高量柱信号可能因单笔大单触发而失真，建议结合成交额绝对值过滤。以上建议为整理者独立分析，非原著或权威理论内容 |
| 来源 | 《量柱擒涨停》（第4版），张得一著，四川人民出版社2021年版，ISBN 9787220120077；同花顺指标平台公开公式（2016年上传，2021年仍可访问），第三方公开公式，仅作参考 |

# 规格卡 2：低量柱

## 元数据

- signal_name：低量柱
- signal_id：low_volume
- spec_version：1.0
- source_book：《量柱擒涨停》（第4版）
- source_chapter：第二单元 量柱擒涨停的六个元素，第8-13章
- effective_confirmation：当日收盘后确认（T日）
- dependencies：无（基础信号）

## 1. 自然语言定义

低量柱是指某一阶段内成交量最低的量柱。量化标准为：当日成交量为最近10个交易日内的最低值，或连续5日以上萎缩至阶段最小量。低量柱反映市场交投清淡、抛压枯竭，是变盘前兆信号。

## 2. 输入数据

| 变量名 | 数据含义 | 数据类型 | 数据来源 |
|:---|:---|:---|:---|
| V[t] | 当日成交量 | float > 0 | 行情数据源（前复权） |
| V[t-1], ..., V[t-9] | 前1至前9日成交量 | float > 0 | 行情数据源（前复权） |

## 3. 精确计算公式

判定标准A（阶段最低量）：

    V[t] = min(V[t-9], V[t-8], ..., V[t])
    即：V[t] = LLV(V, 10)

判定标准B（连续5日萎缩至阶段最小）：

    V[t] < V[t-1] < V[t-2] < V[t-3] < V[t-4]
    且 V[t] = LLV(V, 10)

总判定：

    低量柱 = 标准A OR 标准B

## 4. 判定条件（布尔表达式）

    low_volume[t] = (V[t] == LLV(V, 10)) OR (V[t] < V[t-1] AND V[t-1] < V[t-2] AND V[t-2] < V[t-3] AND V[t-3] < V[t-4] AND V[t] == LLV(V, 10))

## 5. 边界情况

| 情况 | 处理方式 |
|:---|:---|
| V[t-1] == 0（停牌后首日） | 停牌日成交量为0会导致LLV失真，须剔除停牌日后重新计算 |
| 新股上市首日 | 不判定（需上市满10个交易日后启用） |
| 除权除息日 | 使用前复权数据；除权除息导致的成交量异常放大不影响低量柱判定 |
| 数据异常（负数、空值） | 该日数据视为无效，跳过；LLV计算时排除无效数据 |
| 上市不足10日 | 标准A不可用；标准B需至少5个有效交易日 |
| 全天停牌（V[t]==0） | 不判定为低量柱，停牌日排除在计算窗口外 |
| 极端缩量（V[t] < V[t-1] × 0.1） | 标注为“极端缩量，需人工复核”；信号可输出但必须附加人工复核标记，不得直接作为交易依据 |

## 6. 输出格式（JSON）

    {
      "signal_id": "low_volume",
      "signal_name": "低量柱",
      "date": "2026-10-05",
      "is_signal": true,
      "match_criteria": "A",
      "values": {
        "v_t": 8000000,
        "llv_10": 8000000,
        "shrink_days": 3,
        "extreme_shrink": false,
        "needs_human_review": false
      },
      "confirmation_date": "2026-10-05",
      "data_quality": "valid"
    }

注：当 V[t] < V[t-1] × 0.1 时，extreme_shrink 置为 true，needs_human_review 置为 true。

## 7. 确认日定义（零未来函数）

低量柱为当日确认信号，确认日为T日收盘后。仅使用V[t]及V[t-1]至V[t-9]的数据。无未来函数。

## 8. 测试用例

测试用例1（标准A命中）：

- 输入：V[t-9..t-1] = [60, 55, 58, 52, 50, 53, 48, 51, 49]，V[t] = 45
- 计算：LLV(V,10) = 45，V[t] == LLV → 标准A命中
- 预期输出：is_signal = true, match_criteria = "A", extreme_shrink = false

测试用例2（标准B命中）：

- 输入：V[t-4]=80, V[t-3]=70, V[t-2]=60, V[t-1]=50, V[t]=40，且LLV(V,10)=40
- 计算：连续5日递减（80>70>60>50>40）且V[t]==LLV → 标准B命中
- 预期输出：is_signal = true, match_criteria = "B"

测试用例3（极端缩量触发人工复核）：

- 输入：V[t-1]=10000万, V[t]=800万，且LLV(V,10)=800
- 计算：标准A命中；V[t]/V[t-1] = 0.08 < 0.1 → 极端缩量
- 预期输出：is_signal = true, match_criteria = "A", extreme_shrink = true, needs_human_review = true

## 9. 依赖关系说明

低量柱为基础信号，无前置依赖。低量柱是以下信号的输入或组成部分：

- 缩量柱（低量柱可能是缩量柱的末端）
- 黄金柱（后三日缩量验证）
- 凹底淘金（底部低量群识别）

## 10. 参数适配说明

| 项目 | 内容 |

# 规格卡 3：倍量柱

## 元数据

- signal_name：倍量柱
- signal_id：double_volume
- spec_version：1.0
- source_book：《量柱擒涨停》（第4版）
- source_chapter：第二单元 量柱擒涨停的六个元素，第8-13章
- effective_confirmation：当日收盘后确认（T日）
- dependencies：无（基础信号）

## 1. 自然语言定义

倍量柱是指当日成交量比前一日成交量高出一倍以上的量柱。量化标准为：V[t]/V[t-1] ≥ 1.9（即至少高出前日90%以上），且当日收盘价高于前一日收盘价（C[t] > C[t-1]）。倍量柱是资金大幅介入的核心信号，是主力进场的“明牌”。

## 2. 输入数据

| 变量名 | 数据含义 | 数据类型 | 数据来源 |
|:---|:---|:---|:---|
| V[t] | 当日成交量 | float > 0 | 行情数据源（前复权） |
| V[t-1] | 前一日成交量 | float > 0 | 行情数据源（前复权） |
| C[t] | 当日收盘价 | float > 0 | 行情数据源（前复权） |
| C[t-1] | 前一日收盘价 | float > 0 | 行情数据源（前复权） |

## 3. 精确计算公式

量能条件：

    V[t] / V[t-1] ≥ 1.9

价格条件：

    C[t] > C[t-1]

总判定：

    倍量柱 = 量能条件 AND 价格条件

## 4. 判定条件（布尔表达式）

    double_volume[t] = (V[t] / V[t-1] >= 1.9) AND (C[t] > C[t-1])

## 5. 边界情况

| 情况 | 处理方式 |
|:---|:---|
| V[t-1] == 0（停牌后首日） | 不判定（分母为0无意义）；需前一交易日为有效交易日 |
| 新股上市首日 | 不判定（无V[t-1]数据） |
| 除权除息日 | 必须使用前复权数据；除权除息导致的成交量异常变化不适用倍量柱判定 |
| 数据异常（负数、空值） | 该日数据视为无效，不判定 |
| V[t-1] 极小（低于日均成交额10%） | 倍量柱可能因基数过小而误触发，建议增加V[t]绝对成交额过滤（如V[t]对应成交额 > 5000万元） |
| 涨停板（C[t]达到涨幅限制） | 价格条件自动满足，倍量柱判定仍有效 |

## 6. 输出格式（JSON）

    {
      "signal_id": "double_volume",
      "signal_name": "倍量柱",
      "date": "2026-10-05",
      "is_signal": true,
      "values": {
        "v_t": 120000000,
        "v_t_1": 55000000,
        "volume_ratio": 2.18,
        "c_t": 15.20,
        "c_t_1": 14.50,
        "price_change_pct": 4.83
      },
      "confirmation_date": "2026-10-05",
      "data_quality": "valid"
    }

## 7. 确认日定义（零未来函数）

倍量柱为当日确认信号，确认日为T日收盘后。仅使用V[t]、V[t-1]、C[t]、C[t-1]的数据。无未来函数。

## 8. 测试用例

测试用例1（标准倍量柱命中）：

- 输入：V[t-1]=5000万, V[t]=10000万, C[t-1]=10.00, C[t]=10.50
- 计算：V[t]/V[t-1]=2.0 ≥ 1.9；C[t]>C[t-1] → 命中
- 预期输出：is_signal = true

测试用例2（量能达标但价格不达标）：

- 输入：V[t-1]=5000万, V[t]=10000万, C[t-1]=10.00, C[t]=9.80
- 计算：量能比=2.0 ≥ 1.9，但C[t]<C[t-1] → 不命中（放量下跌不是倍量柱）
- 预期输出：is_signal = false

测试用例3（量能不达标）：

- 输入：V[t-1]=5000万, V[t]=9000万, C[t-1]=10.00, C[t]=10.50
- 计算：V[t]/V[t-1]=1.8 < 1.9 → 不命中
- 预期输出：is_signal = false

## 9. 依赖关系说明

倍量柱为基础信号，无前置依赖。倍量柱是以下信号的核心输入：

- 黄金柱（基柱最常见形态）
- 将军柱（基柱候选）
- 凹底淘金（底部倍量柱识别）
- 倍量伸缩（倍量柱与缩量柱交替）

## 10. 参数适配说明

| 项目 | 内容 |
|:---|:---|
| 原著初版参数 | 倍量柱“至少应高出前日量柱的90%以上，即是前日量柱的1.9倍以上”；且要求价格上涨 |
| 最新修订版（2021年第4版）是否更新 | 经检索第4版，倍量柱参数1.9倍阈值未发现更新，沿用初版参数 |
| 其他权威理论补充 | 同花顺指标平台公开公式（2016年上传，2021年仍可访问），第三方公开公式，仅作参考：倍量柱:=IF(V/REF(V,1)>1.9 AND C>REF(C,1),1,0)，与原著一致。部分第三方实现采用2.0倍阈值，但原著明确为1.9倍，本规格以原著为准 |
| 当前市场环境适用性 | 1.9倍阈值在当前市场仍适用。整理者分析，非权威来源：2020年以后A股量化交易占比提升，部分个股出现“量化对倒倍量”（主力对倒制造倍量假象），倍量柱的信号可靠性有所下降，建议结合换手率（倍量柱当日换手率 > 3%）和成交额绝对值过滤。以上建议为整理者独立分析，非原著或权威理论内容 |
| 来源 | 《量柱擒涨停》（第4版），张得一著，四川人民出版社2021年版，ISBN 9787220120077；同花顺指标平台公开公式（2016年上传，2021年仍可访问），第三方公开公式，仅作参考 |

# 规格卡 4：平量柱

## 元数据

- signal_name：平量柱
- signal_id：flat_volume
- spec_version：1.0
- source_book：《量柱擒涨停》（第4版）
- source_chapter：第二单元 量柱擒涨停的六个元素，第8-13章
- effective_confirmation：第二根平量柱收盘后确认（T日）
- dependencies：无（基础信号）

## 1. 自然语言定义

平量柱是指与前一日量柱基本持平的量柱，必须是两根或两根以上连续出现。量化标准为：0.95 ≤ V[t]/V[t-1] ≤ 1.05（允许5%误差），且连续至少2根量柱满足该条件。平量柱反映多空双方力量暂时均衡，是变盘前兆信号。

## 2. 输入数据

| 变量名 | 数据含义 | 数据类型 | 数据来源 |
|:---|:---|:---|:---|
| V[t] | 当日成交量 | float > 0 | 行情数据源（前复权） |
| V[t-1] | 前一日成交量 | float > 0 | 行情数据源（前复权） |
| V[t-2] | 前二日成交量 | float > 0 | 行情数据源（前复权） |

## 3. 精确计算公式

单根平量条件：

    0.95 ≤ V[t] / V[t-1] ≤ 1.05

连续平量条件（至少2根）：

    0.95 ≤ V[t] / V[t-1] ≤ 1.05 AND 0.95 ≤ V[t-1] / V[t-2] ≤ 1.05

总判定：

    平量柱 = 连续至少2根满足单根平量条件

## 4. 判定条件（布尔表达式）

    flat_volume[t] = (V[t] / V[t-1] >= 0.95 AND V[t] / V[t-1] <= 1.05) AND (V[t-1] / V[t-2] >= 0.95 AND V[t-1] / V[t-2] <= 1.05)

注：平量柱的确认以T日为第二根平量柱时确认。若需识别N根连续平量，扩展为V[t]/V[t-1]至V[t-N+1]/V[t-N]均满足条件。

## 5. 边界情况

| 情况 | 处理方式 |
|:---|:---|
| V[t-1] == 0 或 V[t-2] == 0 | 不判定（停牌日数据无效，需至少3个连续有效交易日） |
| 新股上市首日 | 不判定（需至少3个有效交易日） |
| 除权除息日 | 使用前复权数据；除权除息日若在平量序列中，该日成交量可能失真，建议跳过 |
| 数据异常（负数、空值） | 该日数据视为无效，平量序列中断 |
| 仅1根平量 | 不判定（原著要求“两根或两根以上”） |
| 平量柱超过8根 | 仍判定为平量柱，但需标注“超长平量”，变盘概率更高 |

# 规格卡 7：黄金柱

## 元数据

- signal_name：黄金柱

- dependencies：倍量柱（double_volume）、高量柱（high_volume）、梯量柱（ladder_volume）、平量柱（flat_volume）

## 1. 自然语言定义

黄金柱是量学中最重要的量柱形态之一，由“基柱”和“后三日验证”两部分组成。基柱是四种候选形态之一（倍量柱、高量柱、梯量柱第一柱、平量柱第二柱），后三日必须满足核心条件：后三日收盘价的均值 ≥ 基柱实顶 且 后三日成交量均不超过基柱成交量。黄金柱反映主力高度控盘、筹码锁定良好，是后续拉升的核心支撑位。

## 2. 输入数据

| 变量名 | 数据含义 | 数据类型 | 数据来源 |
|:---|:---|:---|:---|
| V[t] | 基柱日（T日）成交量 | float > 0 | 行情数据源（前复权） |
| V[t+1], V[t+2], V[t+3] | 基柱后1-3日成交量 | float > 0 | 行情数据源（前复权） |
| C[t] | 基柱日收盘价 | float > 0 | 行情数据源（前复权） |
| C[t+1], C[t+2], C[t+3] | 基柱后1-3日收盘价 | float > 0 | 行情数据源（前复权） |
| H[t] | 基柱日最高价 | float > 0 | 行情数据源（前复权） |
| O[t] | 基柱日开盘价 | float > 0 | 行情数据源（前复权） |
| L[t+1], L[t+2], L[t+3] | 基柱后1-3日最低价 | float > 0 | 行情数据源（前复权） |

注：当基柱候选为平量柱第二柱时，还需前置数据 V[t-1]、V[t-2]（用于平量柱判定），见测试用例4。

## 3. 精确计算公式

基柱条件（T日）——四种候选之一：

- 倍量柱：double_volume[t]（V[t]/V[t-1] ≥ 1.9 且 C[t] > C[t-1]）
- 高量柱：high_volume[t]（V[t] == HHV(V,10) 或 V[t] > MA3(V) × 1.5）
- 梯量柱第一柱：ladder_volume_first[t]（连续梯量序列的第一根递增柱）
- 平量柱第二柱：flat_volume_second[t]（连续平量序列的第二根持平柱）

基柱候选的精确判定标准：
- 梯量柱第一柱 = 梯量序列的起点（当日递增 V[t] > V[t-1] 且前一日不递增 V[t-1] ≤ V[t-2]）
- 平量柱第二柱 = 平量序列的第二根（当日平量 0.95≤V[t]/V[t-1]≤1.05 且前一日平量 0.95≤V[t-1]/V[t-2]≤1.05 且 T-2日不平量 V[t-2]/V[t-3] 不满足平量条件）

总基柱判定：

    base_pillar[t] = double_volume[t] OR high_volume[t] OR ladder_volume_first[t] OR flat_volume_second[t]

后三日收盘价条件（核心）：

    (C[t+1] + C[t+2] + C[t+3]) / 3 ≥ max(C[t], O[t])

后三日成交量条件（核心）：

    V[t+1] ≤ V[t] AND V[t+2] ≤ V[t] AND V[t+3] ≤ V[t]

不破实顶条件：

    min(L[t+1], L[t+2], L[t+3]) ≥ max(C[t], O[t])

总判定：

    黄金柱 = 基柱条件 AND 后三日收盘价均值条件 AND 后三日量条件 AND 不破实顶条件

可选最强版条件（不作为硬性判定）：

- 价升最强版：后三日收盘价逐日递增：C[t+1] < C[t+2] < C[t+3]
- 量缩最强版：后三日成交量逐日递减：V[t+1] > V[t+2] > V[t+3]

最强版条件用于信号强度分级（golden_volume_strong），不参与黄金柱基础判定。

## 4. 判定条件（布尔表达式）

    golden_volume[t+3] = (double_volume[t] OR high_volume[t] OR ladder_volume_first[t] OR flat_volume_second[t]) AND ((C[t+1] + C[t+2] + C[t+3]) / 3 >= MAX(C[t], O[t])) AND (V[t+1] <= V[t] AND V[t+2] <= V[t] AND V[t+3] <= V[t]) AND (MIN(L[t+1], L[t+2], L[t+3]) >= MAX(C[t], O[t]))

信号强度分级（可选）：

    golden_volume_strong[t+3] = golden_volume[t+3] AND (C[t+1] < C[t+2] < C[t+3]) AND (V[t+1] > V[t+2] > V[t+3])

注：确认日为T+3日（基柱后第三日收盘后）。信号标记的基柱日期为T日。

## 5. 边界情况

| 情况 | 处理方式 |
|:---|:---|
| 基柱日V[t-1]==0（停牌后首日） | 基柱倍量柱判定可能失真，建议基柱需至少3个有效交易日前置数据 |
| 后三日中存在停牌日 | 黄金柱判定失效（后三日必须为连续有效交易日）；停牌后重新计算 |
| 新股上市 | 不判定（需至少10个有效交易日历史数据） |
| 除权除息日 | 必须使用前复权数据；除权除息日若在基柱或后三日中，黄金柱判定可能失效 |
| 数据异常（负数、空值） | 该日数据视为无效，黄金柱判定失效 |
| 后三日收盘价均值达标但量未缩 | 不判定为黄金柱（量缩条件是核心条件之一） |
| 后三日量缩但收盘价均值未达标 | 不判定为黄金柱 |
| 跌破基柱实顶 | 不判定为黄金柱（不破实顶是核心条件之一） |
| 基柱不属于四种候选形态 | 不判定为黄金柱 |
| 后三日中存在极端缩量（V < V[t] × 0.1） | 标注“极端缩量，需人工复核”；信号可输出但附加人工复核标记 |

## 7. 确认日定义（零未来函数）

黄金柱为滞后确认信号，确认日为基柱后第三日收盘后（T+3日）。

- 基柱日（T日）：仅能识别为倍量柱、高量柱、梯量柱第一柱或平量柱第二柱（基柱候选），不能确认黄金柱
- T+1日：可验证第一日量不超过基柱、最低价不破实顶
- T+2日：可验证第二日量不超过基柱、最低价不破实顶
- T+3日收盘后：三日验证完成（收盘价均值、量条件、不破实顶），确认黄金柱

禁止使用未来函数：在T日、T+1日、T+2日均不能确认黄金柱，必须等待T+3日收盘后。信号输出中的 base_pillar_date 标记基柱日，confirmation_date 标记确认日，二者必须明确区分。

## 8. 测试用例

测试用例1（标准黄金柱命中，最强版）：

- 输入（T日基柱）：V[t]=12000万, C[t]=15.20, O[t]=14.50, H[t]=15.30, L[t]=14.40，且V[t]/V[t-1]=2.1（倍量柱）
- T+1：V=9000万, C=15.35, L=15.25
- T+2：V=7500万, C=15.50, L=15.30
- T+3：V=6000万, C=15.80, L=15.45
- 计算：基柱为倍量柱✓；avg_close=(15.35+15.50+15.80)/3=15.55 ≥ 15.20✓；V[t+1..t+3]均≤V[t]✓；min(L)=15.25 ≥ 15.20✓；最强版C递增✓且V递减✓
- 预期输出：is_signal = true, base_pillar_type = "double_volume", strength = "strong"

测试用例2（收盘价均值不达标，不命中）：

- 输入：基柱同测试用例1
- T+1：V=9000万, C=15.00, L=15.25
- T+2：V=7500万, C=15.10, L=15.30
- T+3：V=6000万, C=15.20, L=15.45
- 计算：avg_close=(15.00+15.10+15.20)/3=15.10 < 15.20 → 收盘价均值条件不满足
- 预期输出：is_signal = false

测试用例3（后三日某日量超过基柱，不命中）：

- 输入：基柱同测试用例1
- T+1：V=13000万（超过基柱V[t]=12000万）, C=15.35, L=15.25
- T+2：V=7500万, C=15.50, L=15.30
- T+3：V=6000万, C=15.80, L=15.45
- 计算：V[t+1]=13000 > V[t]=12000 → 量条件不满足
- 预期输出：is_signal = false

测试用例4（平量柱第二柱作为基柱）：

- 输入（T日基柱，需前置数据判定平量柱）：V[t-2]=4980万, V[t-1]=5050万, V[t]=5000万；C[t]=15.20, O[t]=14.50
- 平量柱判定：V[t-1]/V[t-2]=5050/4980=1.014（在[0.95,1.05]内）；V[t]/V[t-1]=5000/5050=0.990（在范围内）→ 连续2根平量成立，T日为平量柱第二柱✓
- T+1：V=4500万, C=15.35, L=15.25
- T+2：V=4200万, C=15.50, L=15.30
- T+3：V=4000万, C=15.60, L=15.45
- 计算：基柱为平量柱第二柱✓；avg_close=(15.35+15.50+15.60)/3=15.48 ≥ 15.20✓；V[t+1..t+3]均≤V[t]=5000万✓；min(L)=15.25 ≥ 15.20✓
- 预期输出：is_signal = true, base_pillar_type = "flat_volume"

## 9. 依赖关系说明

黄金柱为复合信号，依赖以下基础信号：

- 倍量柱（double_volume）：基柱候选之一（最常见）
- 高量柱（high_volume）：基柱候选之一
- 梯量柱（ladder_volume）：基柱候选之一（梯量柱第一柱）
- 平量柱（flat_volume）：基柱候选之一（平量柱第二柱）
- 缩量柱（shrink_volume）：后三日量缩验证的相关信号

黄金柱是以下信号的核心输入：

- 黄金线（基于黄金柱实顶绘制的支撑线）
- 黄金梯（多个黄金柱逐级抬高形成的阶梯）
- 黄金仓（黄金柱与黄金线围成的筹码密集区）
- 金线战法（强庄踩顶、精庄踩腰、狡庄踩脚）
