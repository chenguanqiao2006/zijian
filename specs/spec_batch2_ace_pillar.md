## 1. 自然语言定义

将军柱是量学王牌柱体系中级别最低的一种量柱形态，由“基柱”与“后三日验证”两部分构成。基柱必须是“阳胜柱”——量柱和价柱双双严格胜过其左侧最近阴柱（严格大于，非大于等于），基柱候选包括倍量柱、高量柱、梯量柱第一柱、平量柱第二柱。后三日必须满足两个核心条件：不破实底（后三日收盘价不低于基柱开盘价）且量不过顶（后三日量柱均不超过基柱量柱）。将军柱与黄金柱的区分：基柱后三日收盘价平均低于基柱实顶的为将军柱，平均高于或等于基柱实顶的为黄金柱——“线下是将军，线上是黄金”。

位置-性质声明：原著对将军柱给出了“阳胜柱、三日不破、量不过顶”的形态标准，但未对将军柱在低位/中位/高位的性质给出系统映射【原著未明确，为整理者分析，非权威来源】。将军柱的 position 字段由全局规则文件的位置判定规则计算，nature 字段按下方输出规范取值并附加标注。

## 3. 精确计算公式

基柱条件（T日）——四种候选之一，且为阳胜柱：

- 倍量柱：V[t]/V[t-1] ≥ 1.9 且 C[t] > C[t-1]
- 高量柱：V[t] == HHV(V,10) 或 V[t] > MA3(V) × 1.5
- 梯量柱第一柱：连续梯量序列的第一根递增柱
- 平量柱第二柱：连续平量序列的第二根持平柱

阳胜柱附加条件（严格大于，非大于等于）：

    C[t] > C[left_ying] 且 V[t] > V[left_ying]

即：

    base_pillar[t] = double_volume[t] OR high_volume[t] OR ladder_volume_first[t] OR flat_volume_second[t]
    yang_win[t] = (C[t] > C[left_ying]) AND (V[t] > V[left_ying])

后三日不破实底条件（核心）：

    min(C[t+1], C[t+2], C[t+3]) ≥ O[t]

后三日量不过顶条件（核心）：

    V[t+1] ≤ V[t] AND V[t+2] ≤ V[t] AND V[t+3] ≤ V[t]

将军柱/黄金柱区分条件：

后三日收盘价平均值低于基柱实顶 → 将军柱：

    (C[t+1] + C[t+2] + C[t+3]) / 3 < max(C[t], O[t])

（后三日收盘价平均值高于或等于基柱实顶 → 黄金柱，见批次1规格卡7）

总判定：

    将军柱 = 基柱条件 AND 阳胜柱条件 AND 不破实底条件 AND 量不过顶条件 AND 收盘价均值低于实顶条件

## 4. 判定条件（布尔表达式）

    general_volume[t+3] =
    (double_volume[t] OR high_volume[t] OR ladder_volume_first[t] OR flat_volume_second[t]) AND
    (C[t] > C[left_ying] AND V[t] > V[left_ying]) AND
    (MIN(C[t+1], C[t+2], C[t+3]) >= O[t]) AND
    (V[t+1] <= V[t] AND V[t+2] <= V[t] AND V[t+3] <= V[t]) AND
    ((C[t+1] + C[t+2] + C[t+3]) / 3 < MAX(C[t], O[t]))

注：确认日为T+3日（基柱后第三日收盘后）。信号标记的基柱日期为T日。

## 5. 边界情况

| 情况 | 处理方式 |
|:---|:---|
| 基柱日V[t-1]==0（停牌后首日） | 基柱倍量柱判定可能失真，需至少3个有效交易日前置数据 |
| 后三日中存在停牌日 | 将军柱判定失效（后三日必须为连续有效交易日）；停牌后重新计算 |
| 新股上市 | 不判定（需至少10个有效交易日历史数据） |
| 除权除息日 | 必须使用前复权数据；除权除息日若在基柱或后三日中，将军柱判定可能失效 |
| 数据异常（负数、空值） | 该日数据视为无效，将军柱判定失效 |
| 后三日跌破基柱实底 | 不判定为将军柱（不破实底是核心条件） |
| 后三日量柱超过基柱 | 不判定为将军柱（量不过顶是核心条件） |
| 后三日收盘价平均值高于或等于基柱实顶 | 不判定为将军柱，应判定为黄金柱（见批次1规格卡7测试用例1） |
| 基柱不属于四种候选形态 | 不判定为将军柱 |
| 后三日中存在极端缩量（V < V[t] × 0.1） | 标注“极端缩量，需人工复核”；信号可输出但附加人工复核标记 |
| 位置判定失败（数据不足、区间无效） | position = "unknown"，nature = "无法判定性质"（见全局规则文件第三部分） |

## 7. 确认日定义（零未来函数）

将军柱为滞后确认信号，确认日为基柱后第三日收盘后（T+3日）。

- 基柱日（T日）：仅能识别为倍量柱、高量柱、梯量柱第一柱或平量柱第二柱（基柱候选），不能确认将军柱
- T+1日：可验证第一日收盘价不破实底、量不过顶
- T+2日：可验证第二日收盘价不破实底、量不过顶
- T+3日收盘后：三日验证完成（不破实底、量不过顶、收盘价均值低于实顶），确认将军柱

禁止使用未来函数：在T日、T+1日、T+2日均不能确认将军柱，必须等待T+3日收盘后。输出中的 base_pillar_date 标记基柱日，confirmation_date 标记确认日，二者必须明确区分。position 字段使用T日收盘后可得数据（HHV_250/LLV_250 均为当日及之前数据），不引入未来信息。

## 8. 测试用例

测试用例1（标准将军柱命中）：

- 输入（T日基柱）：V[t]=12000万, V[t-1]=5700万（倍量柱，比值2.1），C[t]=15.20, O[t]=14.50, H[t]=15.30；左侧最近阴柱日 C[left_ying]=14.20, V[left_ying]=6000万（阳胜柱：15.20 > 14.20 且 12000 > 6000，严格胜过）
- T+1：V=9000万, C=15.00
- T+2：V=7500万, C=14.90
- T+3：V=6000万, C=15.10
- 位置判定输入：HHV_250=16.00, LLV_250=14.00，C[t]=15.20 → position_pct = (15.20-14.00)/(16.00-14.00)×100 = 60% → mid
- 计算：基柱为倍量柱且阳胜柱；min(C后三日)=14.90 ≥ O[t]=14.50（不破实底）；V[t+1..t+3]均≤V[t]=12000万（量不过顶）；avg_close=(15.00+14.90+15.10)/3=15.00 < max(C,O)=15.20（低于实顶）
- 预期输出：general_volume = true, base_pillar_type = "double_volume", defense_line_price = 14.50, position = "mid", nature = "趋势中继支撑（原著未明确，为整理者分析，非权威来源）"

测试用例2（阳胜柱条件不满足，不命中）：

- 输入（T日基柱）：V[t]=12000万（倍量柱），C[t]=15.20, O[t]=14.50；左侧最近阴柱日 C[left_ying]=15.20, V[left_ying]=10000万
- 计算：C[t]=15.20 与 C[left_ying]=15.20 相等，C[t] > C[left_ying] 不成立（“胜过”为严格大于）→ 阳胜柱条件不满足
- 预期输出：general_volume = false

测试用例3（后三日跌破实底，不命中）：

- 输入：基柱同测试用例1
- T+1：V=9000万, C=14.80
- T+2：V=7500万, C=14.30（跌破实底14.50）
- T+3：V=6000万, C=15.10
- 计算：min(C后三日)=14.30 < 14.50 → 不破实底条件不满足
- 预期输出：general_volume = false

测试用例4（后三日收盘价均值高于实顶，判定为黄金柱而非将军柱）：

- 输入：基柱同测试用例1
- T+1：V=9000万, C=15.35
- T+2：V=7500万, C=15.50
- T+3：V=6000万, C=15.80
- 计算：avg_close=(15.35+15.50+15.80)/3=15.55 > max(C,O)=15.20 → 高于实顶，不满足将军柱区分条件
- 预期输出：general_volume = false（该形态不满足将军柱区分条件，应判定为黄金柱，见批次1规格卡7测试用例1）

## 9. 依赖关系说明

将军柱为复合信号，依赖以下基础信号：

- 倍量柱（double_volume）：基柱候选之一（最常见）
- 高量柱（high_volume）：基柱候选之一
- 梯量柱（ladder_volume）：基柱候选之一（梯量柱第一柱）
- 平量柱（flat_volume）：基柱候选之一（平量柱第二柱）
- 位置判定（price_position）：全局规则文件定义，输出 position/nature 字段

将军柱是以下信号的核心输入：

- 黄金柱（golden_volume）：基柱后三日收盘价均值高于或等于实顶时升格为黄金柱（“黄金柱必是将军柱”）
- 元帅柱（marshal_volume）：将军柱前方有跳空缺口时，按其左侧量柱授衔为元帅柱（见规格卡2）
- 攻防线：以将军柱后三日最低价（或基柱实底）为参照绘制攻防线/黄金线
- 金线战法：将军柱实底/实顶构成黄金线的取点基础

## 1. 自然语言定义

元帅柱是量学王牌柱体系中级别最高的一种量柱形态，由“先者优先，跳空补空”两大授衔原则确定。核心定义：当王牌柱（将军柱或黄金柱）的基柱前方存在向上跳空缺口时，位于跳空缺口下方（跳空前一日）的价柱即被授衔为元帅柱。其中：跳空缺口要求跳空当日最低价严格高于跳空前一日最高价（L[t] > H[t-1]）；跳空补空原则要求授衔时向前移位至缺口下方量柱；先者优先原则要求多个王牌柱并存时以最先出现的为准。元帅柱与“零号战法”直接相关：跳空缺口处无成交（零成交），故称“零号”。口诀：“元帅出马，一个顶俩”“跳空不补，后市如虎”。

位置-性质声明：原著给出了元帅柱的授衔标准（先者优先、跳空补空、王牌柱三标准），但未对元帅柱在低位/中位/高位的性质给出系统映射【原著未明确，为整理者分析，非权威来源】。元帅柱的 position 字段由全局规则文件的位置判定规则计算，nature 字段按下方输出规范取值并附加标注。

| V[t-1] | 跳空前一日（元帅柱候选日）成交量 | float > 0 | 行情数据源（前复权） |
| V[t+1], V[t+2], V[t+3] | 跳空后1-3日成交量 | float > 0 | 行情数据源（前复权） |
| O[t] | 跳空当日开盘价（基柱实底） | float > 0 | 行情数据源（前复权） |
| L[t] | 跳空当日最低价 | float > 0 | 行情数据源（前复权） |
| H[t-1] | 跳空前一日最高价 | float > 0 | 行情数据源（前复权） |
| C[t-1] | 跳空前一日收盘价 | float > 0 | 行情数据源（前复权） |
| C[t] | 跳空当日收盘价 | float > 0 | 行情数据源（前复权） |
| C[t+1], C[t+2], C[t+3] | 跳空后1-3日收盘价 | float > 0 | 行情数据源（前复权） |
| L[t+1], L[t+2], L[t+3] | 跳空后1-3日最低价 | float > 0 | 行情数据源（前复权） |
| HHV_250, LLV_250 | 近250日最高/最低价 | float > 0 | 行情数据源（前复权），用于 position 计算 |

注：基柱实底 = 跳空当日开盘价 O[t]（唯一值，无第二个口径）；基柱实顶 = max(C[t], O[t])。

## 3. 精确计算公式

跳空缺口条件（T日）：

    向上跳空缺口：L[t] > H[t-1]

王牌柱确认条件（T日基柱，后三日验证）：

    ace_pillar[t] = general_volume[t] OR golden_volume[t]

授衔条件（元帅柱确认）：

    marshal_volume = gap_up[t] AND ace_pillar[t]
    （元帅柱标记日期 = T-1日）

先者优先条件：

    marshal_date = MIN{日期 | 满足授衔条件的 T-1 日期}

跳空不补条件（强化，可选）：

    gap_not_filled = (L[t+1] > H[t-1]) AND (L[t+2] > H[t-1]) AND (L[t+3] > H[t-1])

（缺口回补则按“跳空补空”原则授衔仍可成立，但需标注“缺口已回补”，可靠性降低）

## 4. 判定条件（布尔表达式）

    gap_up[t] = (L[t] > H[t-1])
    ace_pillar[t] = general_volume[t] OR golden_volume[t]
    marshal_volume[t-1] = gap_up[t] AND ace_pillar[t]
    gap_not_filled = (L[t+1] > H[t-1]) AND (L[t+2] > H[t-1]) AND (L[t+3] > H[t-1])

注：确认日为T+3日。元帅柱标记的授衔日期为T-1日，基柱日期为T日，确认日期为T+3日。

## 5. 边界情况

| 情况 | 处理方式 |
|:---|:---|
| 停牌后首日 | 跳空判定需跳空前一日为有效交易日；若停牌后跳空，需人工复核是否为真实跳空 |
| 新股上市首日 | 不判定（无跳空前一日数据） |
| 除权除息日 | 必须使用前复权数据；除权除息造成的“价格跳空”（非真实交易缺口）不得判定为元帅柱 |
| 数据异常（负数、空值） | 该日数据视为无效，元帅柱判定失效 |
| L[t] == H[t-1]（平开无缺口） | 不判定为跳空缺口，信号不成立（跳空缺口要求严格大于） |
| 跳空幅度过小（<1%） | 标注“疑似跳空”；原著提示“跳得太高的（5个点以上）就没有意义了”，跳空幅度超过5%需人工复核 |
| 跳空当日基柱后三日未形成王牌柱 | 不判定为元帅柱（元帅柱必须由后三日王牌柱确认授衔） |
| 跳空缺口后三日内回补 | 按“跳空补空”原则授衔仍可成立，但需标注“缺口已回补”，可靠性降低 |
| 后三日中存在极端缩量（V < V[t] × 0.1） | 标注“极端缩量，需人工复核”；信号可输出但附加人工复核标记 |
| 位置判定失败（数据不足、区间无效） | position = "unknown"，nature = "无法判定性质"（见全局规则文件第三部分） |

position/nature 取值规则（引用 spec_global_rules.md）：

- position：由全局规则文件位置判定规则计算（low / mid / high / unknown）
- nature：元帅柱位置-性质映射【原著未明确，为整理者分析，非权威来源】：
  - low：行情起点信号（底部第一根元帅柱为行情启动标志）
  - mid：趋势加速信号（跳空补空中继）
  - high：跳空补空警示（高位跳空需防“跳得太高没有意义”，警惕诱多）

## 7. 确认日定义（零未来函数）

元帅柱为滞后确认信号，确认日为跳空当日基柱后第三日收盘后（T+3日）。

- T-1日：跳空前一日（元帅柱候选授衔日），此时无法确认
- T日：出现向上跳空缺口，跳空当日形成基柱（倍量柱/高量柱候选），此时仅能识别跳空，不能确认元帅柱
- T+1日、T+2日：验证基柱后三日是否形成王牌柱（将军柱/黄金柱）
- T+3日收盘后：三日验证完成，若基柱形成王牌柱，则T-1日量柱被正式授衔为元帅柱

禁止使用未来函数：在T+3日收盘前不能确认元帅柱。输出中的 marshal_date（T-1日）为授衔标记日，gap_date（T日）为跳空日，confirmation_date（T+3日）为确认日，三者必须明确区分。position 字段使用T日收盘后可得数据（HHV_250/LLV_250 均为当日及之前数据），不引入未来信息。

## 8. 测试用例

测试用例1（标准元帅柱命中：跳空+将军柱确认路径，干净场景）：

- 输入（T-1日，元帅柱候选日）：V=6000万, C=14.50, O=14.20, H=15.00
- 输入（T日跳空日）：O[t]=15.40, L[t]=15.60 > H[t-1]=15.00（跳空成立），V[t]=12000万（倍量柱，V[t]/V[t-1]=2.0），C[t]=15.80, O[t]=15.40（唯一值，实底=开盘价15.40）
- T+1：V=9000万, C=15.60, L=15.45
- T+2：V=7500万, C=15.50, L=15.42
- T+3：V=6000万, C=15.55, L=15.48
- 位置判定输入：HHV_250=20.00, LLV_250=14.00，C[t]=15.80 → position_pct = (15.80-14.00)/(20.00-14.00)×100 = 30% → mid
- 计算路径：跳空成立（L[t]=15.60 > H[t-1]=15.00）；基柱倍量柱（12000/6000=2.0 ≥ 1.9）；阳胜柱成立（前提满足）；min(C后三日)=15.50 ≥ O[t]=15.40（不破实底）；V[t+1..t+3]均≤V[t]=12000万（量不过顶）；avg_close=(15.60+15.50+15.55)/3=15.55 < max(C,O)=15.80（收盘价均值低于实顶）→ 判定为将军柱路径
- 缺口回补核查：min(L后三日)=15.42 > H[t-1]=15.00 → 缺口未回补（gap_not_filled = true）
- 预期输出：marshal_volume = true, ace_pillar_type = "general_volume", gap_not_filled = true, position = "mid", nature = "趋势加速信号（原著未明确，为整理者分析，非权威来源）"

测试用例2（平开无缺口，不命中）：

- 输入（T日）：L[t]=15.00, H[t-1]=15.00（平开无缺口，L[t] == H[t-1]）
- 计算：L[t] > H[t-1] 不成立 → 跳空缺口条件不满足
- 预期输出：marshal_volume = false

测试用例3（跳空但基柱后三日未形成王牌柱，不命中）：

- 输入（T日跳空）：O[t]=15.40, L[t]=15.60 > H[t-1]=15.00（跳空成立），V[t]=12000万（倍量柱）
- T+1：V=9000万, C=14.60（跌破基柱实底15.40）, L=14.50
- T+2：V=13000万（量超基柱12000万）, C=14.80
- T+3：V=6000万, C=14.70
- 计算：后三日量超基柱（V[t+2]=13000 > 12000）→ 量不过顶条件不满足；且收盘价跌破实底（C[t+1]=14.60 < 15.40）→ 不破实底条件不满足 → 将军柱/黄金柱均不成立，无王牌柱确认
- 预期输出：marshal_volume = false（跳空成立但无王牌柱确认，不授衔）

测试用例4（高位跳空，position=high，验证 nature 映射到“跳空补空警示”）：

- 输入（T-1日，元帅柱候选日）：V=6000万, C=17.80, O=17.50, H=18.00
- 输入（T日跳空日）：O[t]=18.40, L[t]=18.60 > H[t-1]=18.00（跳空成立），V[t]=12000万（倍量柱，V[t]/V[t-1]=2.0），C[t]=18.50, O[t]=18.40（唯一值，实底=开盘价18.40）
- T+1：V=9000万, C=18.45, L=18.45
- T+2：V=7500万, C=18.42, L=18.42
- T+3：V=6000万, C=18.48, L=18.48
- 位置判定输入：HHV_250=20.00, LLV_250=14.00，C[t]=18.50 → position_pct = (18.50-14.00)/(20.00-14.00)×100 = 75% > 70 → high
- 计算路径：跳空成立（L[t]=18.60 > H[t-1]=18.00）；基柱倍量柱（12000/6000=2.0 ≥ 1.9）；阳胜柱成立（前提满足）；min(C后三日)=18.42 ≥ O[t]=18.40（不破实底）；V[t+1..t+3]均≤V[t]=12000万（量不过顶）；avg_close=(18.45+18.42+18.48)/3=18.45 < max(C,O)=18.50（收盘价均值低于实顶）→ 判定为将军柱路径
- 缺口回补核查：min(L后三日)=18.42 > H[t-1]=18.00 → 缺口未回补（gap_not_filled = true）
- 预期输出：marshal_volume = true, ace_pillar_type = "general_volume", gap_not_filled = true, position = "high", nature = "跳空补空警示（高位跳空需防'跳得太高没有意义'，警惕诱多）（原著未明确，为整理者分析，非权威来源）"

## 9. 依赖关系说明

元帅柱为复合信号，依赖以下基础信号：

- 将军柱（general_volume）：王牌柱确认路径之一（见规格卡1）
- 黄金柱（golden_volume）：王牌柱确认路径之一（见批次1规格卡7）
- 倍量柱（double_volume）：跳空当日基柱常见形态
- 高量柱（high_volume）：跳空当日基柱常见形态
- 位置判定（price_position）：全局规则文件定义，输出 position/nature 字段

元帅柱是以下信号的核心输入：

- 零号战法：元帅柱与跳空缺口（零号区间）构成零号战法的基础（“踩零不破，确认即攻”）
- 攻防线：元帅柱实底构成主力攻防线；“元帅柱被打破庄家就完蛋了”
- 一轮行情的起点：底部第一根元帅柱是行情启动标志
