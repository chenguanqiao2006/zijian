### 元数据

| dependencies | 高量柱（spec_high_volume）、黄金柱（spec_golden_volume）、位置判定（spec_global_rules.md） |

### 1. 自然语言定义

峰顶线是连接阶段性真顶（对应高量柱或黄金柱的顶部）形成的水平线，是测顶攻顶的预警线。它可以充当阻力线；当股价有效突破峰顶线后，峰顶线发生"双向异化"，由压力线转化为支撑线（顶底互换），此时峰顶线与谷底线重合可形成峰谷线。

原著出处（原文）："第一元素：峰顶线。它是阶段性最高点的一道水平线，它可以充当阻力线，有时也可以与谷底线重合，形成特殊的'峰谷线'。"（《量线捉涨停》（第4版）第4讲第二节"量线的七大元素"，张得一著，四川人民出版社2021年版，ISBN 9787220120084）

### 2. 取点规则

有效取点（真顶）须同时满足：
- 取点K线为阶段性最高价（在其左侧至少N根K线内为最高，N为观察窗口，原著未给出量化N【未能核实】，工程化建议N≥5，整理者分析）；
- 取点K线对应量柱为高量柱或黄金柱（量线生根穴位之"真顶/王牌"）；
- 取点价位取K线最高价（虚顶）或实体最高价（实顶），原著取点原则"先找实，后找虚"，优先取实顶；
- 跳空高开的K线无根基，取点应在"缺口柱"上（《股海明灯》专用术语选编，非原著，为二次整理资料，仅作线索参考）。

### 3. 画线公式

水平线，价位等于取点K线的最高价（或实顶价）：

  line_price = H[anchor]   （取虚顶时）
  line_price = max(O[anchor], C[anchor])   （取实顶时，优先）

其中 anchor 为取点K线索引，anchor ≤ T（零未来函数）。

### 4. 有效性判定

一条峰顶线在以下条件下才算"有效量线"：
- 取点已确认为阶段性真顶（后续至少1根K线最高价 < 取点最高价）；
- 取点K线对应量柱为高量柱或黄金柱（量线生根）；
- 画线后，股价在该线附近至少出现1次"触线回落"（验证其压力作用），或1次"有效突破后回踩不破"（验证其异化后的支撑作用）；
- 若取点后股价直接突破且未回踩，该线为"未验证线"，标注 confidence = "unconfirmed"。

### 5. 攻防逻辑

- 股价在峰顶线下方：峰顶线为压力线，股价触线不过→看跌（防守）；
- 股价有效突破峰顶线（实体收盘价 > line_price）：压力减弱，进入"攻"的节奏；
- 突破后回踩峰顶线不破：峰顶线异化为支撑线（顶底互换），进入"守"的节奏，可介入；
- 回踩跌破峰顶线（实体收盘价 < line_price）：异化失败，重新转为压力，应出货。

原著出处："量线的双向异化……左侧是峰顶，右侧是谷底，异化为峰谷线"（《量线捉涨停》（第4版）第5讲第一节，张得一著，四川人民出版社2021年版，ISBN 9787220120084）

### 6. 边界情况

| 情况 | 处理方式 |
|---|---|
| 取点K线为当日（T日）新高，后续未确认 | 不画线，标注"待确认"，零未来函数要求不得用T日作为已确认真顶 |
| 取点后股价连续创新高 | 原取点失效，应移至最新真顶重新画线（动态调整，原著第4讲第三节"量线的动态调整"） |
| 停牌后首日 | 停牌日保留在观察窗口内；停牌超过观察窗口则取点失效 |
| 新股上市首日 | 不判定（数据不足，无左侧参照） |
| 除权除息日 | 必须使用前复权数据，否则价位失真 |
| 数据异常（负数、空值） | 该日无效，取点时排除 |
| 上影线刺破但实体未破 | 无效突破（虚顶突破无效），以实体收盘价为准 |

### 8. 确认日定义（零未来函数）

- 取点日（anchor日）收盘后：可初步标记为"候选真顶"，但不得画线；
- 确认日：anchor日之后至少1根K线（T+1日）收盘后，若 H[T+1] < H[anchor]，则确认 anchor 为真顶，可画线；
- 若 T+1 日 H[T+1] ≥ H[anchor]（创新高），则原取点失效，移至 T+1 日重新等待确认；
- 禁止使用未来数据反推取点。

### 9. 测试用例

用例1（标准）：
- 输入：T-5日 H=15.00（对应高量柱），T-4至T-1日 H 分别为14.80/14.60/14.70/14.50（均<15.00），T日 C=14.40
- 计算：anchor=T-5，line_price=15.00，已确认（后续4日H均<15.00）
- 预期输出：is_valid=true, line_price=15.00, confidence=confirmed

用例2（边界·待确认）：
- 输入：T日 H=15.50（创近期新高，对应高量柱），T+1日数据尚未产生
- 计算：零未来函数要求，T日不得确认为真顶
- 预期输出：is_valid=false, 标注"待确认，需T+1日验证"

用例3（失效·取点被超越）：
- 输入：T-5日 H=15.00，T-3日 H=15.20（超过15.00）
- 计算：15.00不是阶段性高点，取点失效
- 预期输出：is_valid=false, 标注"取点被后续高点超越，应移至15.20重新确认"

| effective_confirmation | 取点K线形成后，需后续至少1根K线确认其为阶段性真底（后续K线最低价 > 取点最低价），确认日为后续确认K线收盘后 |
| dependencies | 低量柱（spec_low_volume）、黄金柱（spec_golden_volume）、位置判定（spec_global_rules.md） |

### 1. 自然语言定义

谷底线是连接阶段性真底（对应低量柱或黄金柱的底部）形成的水平线，是探底回升的生命线。它可以充当支撑线；当股价有效跌破谷底线后，谷底线发生"双向异化"，由支撑线转化为压力线（底顶互换）。

原著出处（原文）："第二元素：谷底线。它是阶段性最低点的一道水平线，它可以充当支撑线，有时又可以成为阻力线，有时可以与峰顶线重合，形成特殊的'峰谷线'。"（《量线捉涨停》（第4版）第4讲第二节，张得一著，四川人民出版社2021年版，ISBN 9787220120084）

### 2. 取点规则

有效取点（真底）须同时满足：
- 取点K线为阶段性最低价（在其左侧至少N根K线内为最低，N≥5，整理者分析）；
- 取点K线对应量柱为低量柱或黄金柱（量线生根穴位之"真底/王牌"）；
- 取点价位取K线最低价（虚底）或实体最低价（实底），原著取点原则"先找实，后找虚"，优先取实底；
- 横势预测时，以谷底线为参照，将横盘处高点连线判断方向（原著第7讲第五节）。

### 3. 画线公式

水平线，价位等于取点K线的最低价（或实底价）：

  line_price = L[anchor]   （取虚底时）
  line_price = min(O[anchor], C[anchor])   （取实底时，优先）

其中 anchor ≤ T（零未来函数）。

### 4. 有效性判定

- 取点已确认为阶段性真底（后续至少1根K线最低价 > 取点最低价）；
- 取点K线对应量柱为低量柱或黄金柱；
- 画线后，股价在该线附近至少出现1次"触线反弹"（验证支撑作用），或1次"有效跌破后反抽不过"（验证异化后的压力作用）；
- 若取点后股价直接跌破且未反抽，该线为"未验证线"。

### 5. 攻防逻辑

- 股价在谷底线上方：谷底线为支撑线，股价触线不破→看涨（防守/持有）；
- 股价有效跌破谷底线（实体收盘价 < line_price）：支撑失效，进入"防"的节奏，应出货；
- 跌破后反抽谷底线不过：谷底线异化为压力线（底顶互换），反抽是出货机会；
- 低位谷底线多次触线不破：支撑力度增强，是"探底回升"的生命线。

原著出处：谷底线"三个功能"——预测升势、预测跌势、预测横势（《量线捉涨停》（第4版）第7讲第二节，张得一著，四川人民出版社2021年版，ISBN 9787220120084）

### 6. 边界情况

### 1. 自然语言定义

平衡线是取关键量柱（将军柱/黄金柱/倍量柱）或关键K线（大阴实顶/大阳实底）对应价位画出的水平线，是多空共享的警戒线，具有支撑压力双重功能。它是量价阴阳交换转移的均衡线，也是多空双方较量暂时平衡的标识线。

原著出处（原文）："第三元素：平衡线。特指多空力量在某个阶段均衡对峙的水平线。它是量价阴阳交换转移的均衡线，也是多空双方较量暂时平衡的标识线。……它有时是阻力线，有时是支撑线，更多情况是另一轮行情的起跑线。因此，平衡线是量线的精灵。"（《量线捉涨停》（第4版）第4讲第二节，张得一著，四川人民出版社2021年版，ISBN 9787220120084）

### 2. 取点规则

取点原则（原著第8讲第一节）："上行找实顶，下行找实底，实点靠整点，无点找密点。"

有效取点来源（七个生根穴位）：
- 大阴实顶（下跌趋势中，取大阴线实体顶部）；
- 大阳实底（上升趋势中，取大阳线实体底部）；
- 将军柱/黄金柱的实顶或实底（王牌柱）；
- 倍量柱的实顶（倍阳）；
- 左峰（左侧最近高峰的实顶）。

三个平衡点（原著）：实点平衡（取实体价位）、整点平衡（取整数价位）、密点平衡（取密集成交区价位）。

### 3. 画线公式

水平线，价位取决于取点类型：

  上行趋势：line_price = max(O[anchor], C[anchor])   （找实顶）
  下行趋势：line_price = min(O[anchor], C[anchor])   （找实底）
  整点平衡：line_price = round(关键价位, 0)   （取整数，整理者分析）
  密点平衡：line_price = 密集成交区均价   （整理者分析，原著未给量化公式【未能核实】）

### 4. 有效性判定

- 取点K线为关键量柱或关键K线（七个生根穴位之一）；
- 画线后，股价在该线附近出现"碰线""咬线""坐线"等行为（验证平衡线的警戒作用）；
- 平衡线的"双重性格"：既可支撑又可压力，取决于股价在线上还是线下；
- 若取点后股价远离平衡线且未回踩，该线为"未验证线"。

### 5. 攻防逻辑

- 股价由下向上："碰线择机而退，咬线择机而进"（原著第8讲第三节倾向暗示）；
- 股价由上而下："碰线择机介入，穿线择机而出"；
- 横盘时：密集区在下，走势向上；密集区在上，走势向下；
- 咬线看涨：K线实体咬在平衡线上，阳多阴少、红肥绿瘦→看涨（原著术语选编，非原著，为二次整理资料，仅作线索参考）。

原著出处："平衡线具有撑力和阻力，是'撑阻线'；可进攻可防守，是'攻防线'。"（《量线捉涨停》（第4版）第8讲第二节，张得一著，四川人民出版社2021年版，ISBN 9787220120084）

### 6. 边界情况

| 情况 | 处理方式 |
|---|---|
| 取点为将军柱/黄金柱但后三日未确认 | 不画线，等待后三日确认（零未来函数） |
| 取点为大阴实顶但该阴线为假阴真阳 | 取点失效（假阴的实顶不代表真实压力），应重新取点 |

| dependencies | 峰顶线（peak_line）、谷底线（valley_line）、平衡线（balance_line）、位置判定（spec_global_rules.md） |

### 1. 自然语言定义

斜衡线是倾斜的平衡线，是某阶段最近的两个重要价位（或点位）的连线所形成的斜线，是量价与时空的坐标线，量学首创。如果说平衡线是空间平衡线，斜衡线则是时间平衡线。斜衡线所表示的行情走向带有一定的趋势（上升趋势/下降趋势），所以又可称之为趋势线。量学的趋势线与传统的趋势线大不相同。

原著出处（原文）："第四元素：斜衡线。……斜衡线就是倾斜的平衡线。它是某阶段最近的两个重要价位（或点位）的连线所形成的斜线。如果说平衡线是空间平衡线，斜衡线则是时间平衡线。"（《量线捉涨停》（第4版）第4讲第二节，张得一著，四川人民出版社2021年版，ISBN 9787220120084）

### 2. 取点规则

有效取点（两个同方向拐点）：
- 上升斜衡线：连接两个阶段性真底（低点抬高），取点K线对应量柱为低量柱或黄金柱；
- 下降斜衡线：连接两个阶段性真顶（高点降低），取点K线对应量柱为高量柱；
- 太极线（高级斜衡线）：根据七个穴位画线，形式上分为底底、顶顶、底顶、顶底四种连线（股海明灯论坛量学知识要点帖，官方论坛文献）；
- 取点优先"先找实，后找虚"，优先取实体价位；
- 两个取点之间应有足够的时间间隔（原著未给量化间隔【未能核实】，工程化建议间隔≥3根K线，整理者分析）。

### 3. 画线公式

斜线，由两个取点 (date1, price1) 和 (date2, price2) 确定：

  斜率 k = (price2 - price1) / (date2 - date1)
  截距 b = price1 - k × date1
  任意日 t 的线价：line_price(t) = k × t + b

其中 date1 < date2 ≤ T（零未来函数）。

平行判定：两条斜衡线平行当且仅当 |k1 - k2| < ε（ε为容差，原著未给量化值【未能核实】，工程化建议ε=0.001，整理者分析）。

### 4. 有效性判定

- 两个取点均已确认为有效拐点（真顶/真底）；
- 画线后，股价在该线附近至少出现1次"触线反弹"（上升斜衡线）或"触线回落"（下降斜衡线）；
- 斜衡线的斜率应与趋势方向一致（上升斜衡线k>0，下降斜衡线k<0）；
- 若取点后股价直接穿越斜衡线且未回踩，该线为"未验证线"。

### 5. 攻防逻辑

- 上升斜衡线：股价在线上方为强势，回踩线不破→看涨（防守/持有）；有效跌破线→看跌（出货）；
- 下降斜衡线：股价在线下方为弱势，反抽线不过→看跌（防守）；有效突破线→看涨（介入）；
- 平斜交叉：平衡线与斜衡线交叉处为"临界点"，叉上看涨，叉下看跌（股海明灯论坛，官方论坛文献）；
- 斜顶起柱：斜衡线顶部出现倍量柱→"斜顶起柱，奔若脱兔"（股海明灯论坛，官方论坛文献）。

原著出处：斜衡线"量学的趋势线与传统的趋势线大不相同"（《量线捉涨停》（第4版）第4讲第二节，张得一著，四川人民出版社2021年版，ISBN 9787220120084）

### 6. 边界情况

| 情况 | 处理方式 |
|---|---|
| 两个取点间隔<3根K线 | 标注"短间隔斜衡线，可靠性低"（整理者分析） |
| 取点之一为当日（T日）拐点，后续未确认 | 不画线，等待确认（零未来函数） |
| 斜率接近0（|k|<ε） | 该线退化为平衡线，应改用平衡线规格卡 |
| 取点为跳空缺口 | 取点应在缺口柱上（原著跳空取点规则） |
| 停牌后首日 | 停牌日保留在时间轴上，斜率计算包含停牌日 |
| 新股上市首日 | 不判定（数据不足） |
| 除权除息日 | 必须使用前复权数据，否则斜率失真 |

| dependencies | 峰顶线（peak_line）、谷底线（valley_line）、精准线（precision_line）、黄金柱（spec_golden_volume）、位置判定（spec_global_rules.md） |

### 1. 自然语言定义

峰谷线是阶段性的峰顶线与谷底线自然重合而成的特殊量线，是顶底互换的进攻线，又称"风骨线"。在所有的量线中，只有它的力道是单向的，即向上支撑股价或指数。峰谷线稀罕少见，攻击力强，往往涨势凶猛，屡创新高。

原著出处（原文）："峰谷线。峰谷线是一种特殊的复合线，它是阶段性的'峰顶线'与'谷底线'自然重合而成的，所以称之为'峰谷线'，也可称之为'顶底线'，其独特的'顶底互换'功能，是许多股票牛气冲天的基础。在所有的量线中，只有它的力道是单向的，即向上支撑股价或指数。"（《量线捉涨停》（第4版）第4讲第二节，张得一著，四川人民出版社2021年版，ISBN 9787220120084）

### 2. 取点规则

峰谷线的形成需要两个取点：
- 左侧取点：阶段性真顶（峰顶线取点），对应高量柱或黄金柱；
- 右侧取点：阶段性真底（谷底线取点），对应低量柱或黄金柱；
- 两个取点的价位"自然重合"（峰顶线价位 = 谷底线价位，或在容差范围内重合）；
- 峰谷线有单峰顶、群峰顶、单谷底和群谷底之分，群峰"峰谷线"支撑力度最强，群底"峰谷线"参考价值最高（原著术语选编，非原著，为二次整理资料，仅作线索参考）。

### 3. 画线公式

水平线，价位等于峰顶线与谷底线重合的价位：

  line_price = peak_line_price = valley_line_price
  重合条件：|peak_line_price - valley_line_price| ≤ δ

其中 δ 为重合容差，原著要求"自然重合"（完全重合），实际数据中需容差，原著未给量化δ【未能核实】，工程化建议δ=0.01元（整理者分析）。

### 4. 有效性判定

- 峰顶线已确认为有效（取点为真顶，对应高量柱/黄金柱）；
- 谷底线已确认为有效（取点为真底，对应低量柱/黄金柱）；
- 两条线价位重合（在容差δ内）；
- 股价突破原峰顶线后，回踩该重合线不破（实体收盘价 ≥ line_price），确认顶底互换；
- 若回踩跌破（实体收盘价 < line_price），则峰谷线异化失败。

### 5. 攻防逻辑

- 峰谷线只有单向力道：向上支撑（原著"只有它的力道是单向的"）；
- 股价在峰谷线上方：强支撑，回踩不破→看涨，可介入；
- 股价跌破峰谷线：单向支撑失效，应坚决出货（原著"相反，如果股价跌破了这些'峰谷线'，就是坚决出货的时机"）；
- 三级飞跃（原著第5讲第二节）：
  - 第一级：峰顶线异化为峰谷线（顶底互换）；
  - 第二级：精准线武装的峰谷线→精准峰谷线（"精准峰谷线，涨停无悬念"）；
  - 第三级：黄金柱支撑的峰谷线→黄金顶（"顶底互换，涨幅翻番"）。

原著出处："量线的三级飞跃有一个共性……第一层，直接将'峰顶线'异化为'峰谷线'……第二层，通过'精准线'武装的'峰谷线'，它就成了'精准峰谷线'……第三层，通过'黄金柱'支撑的'峰谷线'，它就演化成'黄金顶'。"（《量线捉涨停》（第4版）第5讲第二节，张得一著，四川人民出版社2021年版，ISBN 9787220120084）

### 6. 边界情况

| 情况 | 处理方式 |
|---|---|
| 峰顶线与谷底线价位差>δ | 不构成峰谷线，标注"未重合" |
| 峰顶线或谷底线未确认 | 不判定峰谷线，等待两条线均确认 |
| 回踩时上影线刺破但实体未破 | 有效支撑（虚底刺破无效），以实体收盘价为准 |
| 群峰/群底峰谷线 | 支撑力度更强，标注"群峰峰谷线"或"群底峰谷线" |
| 停牌后首日 | 停牌日保留在窗口内 |
| 除权除息日 | 必须使用前复权数据，否则重合判定失真 |

## 规格卡 6：精准线（precision_line）

### 元数据

| 字段 | 值 |

| spec_version | 1.0 |

| dependencies | 峰顶线（peak_line）、谷底线（valley_line）、斜衡线（slant_line）、位置判定（spec_global_rules.md） |

### 1. 自然语言定义

精准线是多个K线的关键价位（开盘价/收盘价/最高价/最低价）在同一价位精确重合形成的线，是主力精确操盘的指纹线，稀有且金贵。精准线有两种情况：水平精准线（两个或两个以上同等价位完全重合在一条水平线上）和倾斜精准线（三个或三个以上不等价位无缝切合在一条倾斜线上）。

原著出处（原文）："第六元素：精准线。有两种情况。第一种情况是水平精准线：即某阶段内两个或两个以上的同等价位（或点位）完全重合在一条水平线上。……第二种情况是倾斜精准线：即某阶段内三个或三个以上的不等价位（或点位）无缝切合在一条倾斜线上。"（《量线捉涨停》（第4版）第4讲第二节，张得一著，四川人民出版社2021年版，ISBN 9787220120084）

### 2. 取点规则

水平精准线取点：
- 至少2个K线的关键价位（开盘/收盘/最高/最低）在同一价位完全重合；
- 取点价位类型须一致（同为最高价、同为最低价、同为收盘价等）；
- 同向相切（如两个最高点同向相切）或双向相切（最高点与最低点相切）；
- 取点K线对应量柱应为关键量柱（王牌/倍阳/大阴/大阳）。

倾斜精准线取点：
- 至少3个K线的关键价位无缝切合在一条倾斜线上；
- 不要求"同价同线"，只要求"多价同线"；
- 倾斜精准线不一定是太极线，但太极线一定是精准斜衡线（原著）。

### 3. 画线公式

水平精准线：

  line_price = P（重合价位）
  重合条件：对所有取点i，|price_i - P| ≤ δ_h

其中 δ_h 为水平重合容差，原著要求"完全重合"，实际需容差，原著未给量化δ_h【未能核实】，工程化建议δ_h=0.01元（整理者分析）。

倾斜精准线：

  对所有取点i，|price_i - (k × date_i + b)| ≤ δ_s
  其中 k, b 由最小二乘法或首尾两点法确定

δ_s 为倾斜切合容差，原著要求"无缝切合"，实际需容差，原著未给量化δ_s【未能核实】，工程化建议δ_s=0.02元（整理者分析）。

### 4. 有效性判定

- 水平精准线：至少2个取点重合（在容差δ_h内），取点类型一致；
- 倾斜精准线：至少3个取点切合（在容差δ_s内）；
- 取点K线对应量柱为关键量柱（量线生根）；
- 精准线的"方向性"：最低点形成精准线→预示上涨；最高点形成精准线→预示下跌；股价站在精准线上方→预示上涨；躲在精准线下方→预示下跌（原著第11讲第四节）；
- 精准线的"该×不×战术"：该涨不涨→下跌，该跌不跌→上涨（原著）。

### 5. 攻防逻辑

- 水平精准线（最低点同向相切）：强支撑，回踩不破→看涨；
- 水平精准线（最高点同向相切）：强压力，触线不过→看跌；
- 水平精准线（双向相切）：支撑压力双重功能，顶底互换；
- 倾斜精准线：与斜衡线攻防逻辑一致，但精准度更高，爆发力更强；
- 回踩精准线："回踩精准线，涨停在眼前"（原著口诀，股海明灯论坛官方论坛文献）；
- 并肩精准线："并肩精准线，起跳如脱兔"；隔日精准线："隔日精准线，前冲似奔鹿"；复合精准线："复合精准线，上冲赛雄鹰"（原著术语选编，非原著，为二次整理资料，仅作线索参考）。

### 6. 边界情况

| 情况 | 处理方式 |
|---|---|
| 仅1个取点（水平）或2个取点（倾斜） | 不构成精准线，标注"取点不足" |
| 取点价位差>容差δ | 不构成精准线，标注"未重合/未切合" |
| 取点类型不一致（最高与最低混合） | 为双向相切精准线，标注"双向相切"，有效性需额外验证 |
| 取点K线对应量柱非关键量柱 | 标注"未生根精准线，可靠性低"（整理者分析） |
| 除权除息日 | 必须使用前复权数据，否则精准重合判定失真 |
| 数据异常（负数、空值） | 该日无效，取点时排除 |

### 1. 自然语言定义

灯塔线是以黄金柱的实顶为中心，由平衡线与斜衡线相交于黄金柱实顶这个中心而形成的光芒四射的一组量线，是趋势与趋幅的导航线。灯塔线是斜衡线的精华，是以量学的"七个穴位"为基础生成的斜衡线，具有神奇的预测魅力。

原著出处（原文）："第七元素：灯塔线。灯塔线是以黄金柱的实顶为中心，由平衡线与斜衡线相交于黄金柱实顶这个中心而形成的光芒四射的一组量线。"（《量线捉涨停》（第4版）第4讲第二节，张得一著，四川人民出版社2021年版，ISBN 9787220120084）

### 2. 取点规则

灯塔线的取点（原著第12讲第五节）：
- 中心取点：黄金柱的实顶（max(O,C)），黄金柱须已确认（后三日验证）；
- 平衡线取点：以黄金柱实顶为价位画水平线（平衡线）；
- 斜衡线取点：以黄金柱实顶为端点，与左侧关键穴位（大阴/大阳/真底/真顶/王牌/倍阳/左峰）连线形成斜衡线；
- 灯塔线是一组线（多条射线），不是单一线；
- 原著提到"灯塔线的有效射程"（第12讲第四节），即灯塔线的预测有时间范围限制，原著未给量化射程【未能核实】。

### 3. 画线公式

灯塔线由以下线组成：

  中心：center_price = max(O[golden_pillar], C[golden_pillar])
  center_date = date[golden_pillar]

  平衡线（水平射线）：line_price(t) = center_price，t ≥ center_date

  斜衡线（射线）：对每个左侧关键穴位点 (date_i, price_i)，
    斜率 k_i = (center_price - price_i) / (center_date - date_i)
    线价：line_price(t) = center_price + k_i × (t - center_date)，t ≥ center_date

  灯塔线 = {平衡线} ∪ {所有斜衡线射线}

### 4. 有效性判定

- 黄金柱已确认（后三日收盘价均值 ≥ 基柱实顶，后三日量均 ≤ 基柱量）；
- 中心取点为黄金柱实顶；
- 斜衡线取点为左侧关键穴位（七个穴位之一）；
- 灯塔线的"有效射程"内（原著未给量化射程【未能核实】），股价沿灯塔线方向运行；
- 若股价偏离灯塔线且未回归，该灯塔线为"失效灯塔线"；
- 灯塔线的"长效机制"（原著第12讲第三节）：优质灯塔线可长期指引航向，但需动态调整。

### 5. 攻防逻辑

- 灯塔线是"导航线"，指引趋势与趋幅；
- 股价沿灯塔线上轨运行：强势，可持有；
- 股价回踩灯塔线下轨不破：支撑确认，可介入；
- 股价跌破灯塔线下轨：趋势可能反转，应出货；
- 灯塔线交汇处（平衡线与斜衡线交叉于黄金柱实顶）：为关键临界点，"平斜交叉处中到大阳出"（股海明灯论坛，官方论坛文献）；
- 灯塔线的"精准预测"（原著第12讲第二节）：可预测股价的顶底和时间窗口，但预测为概率性质，需后续验证。

### 6. 边界情况

| 情况 | 处理方式 |

| 黄金柱未确认（后三日未完成） | 不画灯塔线，等待黄金柱确认（零未来函数） |

| 停牌后首日 | 停牌日保留在时间轴上 |

### 元数据

### 1. 自然语言定义

通道线是由两条平行的斜衡线（或平衡线）组成的"通道"，上轨为压力线，下轨为支撑线，是趋向与趋幅的回归线，是量价时空的综合体现。若以斜衡线为基线画出与之平行的线，就是通道线。原著第13讲还论述了"通道线与无形之手""通道线与量价时空""通道线与太极通道"。

原著出处（原文）："若以斜衡线为基线画出与之平行的线，就是'通道线'。通道线的上轨往往是阻力线，通道线的下轨往往是支撑线。"（《量线捉涨停》（第4版）第4讲第二节，张得一著，四川人民出版社2021年版，ISBN 9787220120084）

### 2. 取点规则

通道线的三维画法（股海明灯论坛量学精华帖，官方论坛文献；原著第13讲"太极通道"）：
- 地线（下轨）：以至少2个点以上的最低价连线（上升通道）或最高价连线（下降通道）；
- 天线（上轨）：以离地线最近的那个最高量柱对应的K线连结两点（上升通道）或最低量柱对应的K线连结两点（下降通道）；
- 人线（中轨）：以地线趋向基本一致的三个最低点的连线（上升通道）；
- 上升通道：以最近的两个最低点连线为下轨，作平行线为上轨；
- 下降通道：以最近的两个最高点连线为上轨，作平行线为下轨。

### 3. 画线公式

上升通道：

  下轨（地线）：由两个真底 (date1, low1) 和 (date2, low2) 确定
    k = (low2 - low1) / (date2 - date1)
    b_low = low1 - k × date1
    lower_price(t) = k × t + b_low

  上轨（天线）：与下轨平行，截距为 b_high = b_low + channel_width
    channel_width = max(近期最高价 - 对应下轨价) （整理者分析，原著未给量化公式【未能核实】）
    upper_price(t) = k × t + b_high

  中轨（人线）：与下轨平行，截距为 b_mid = (b_low + b_high) / 2
    mid_price(t) = k × t + b_mid

下降通道方向相反（上轨由真顶连线确定，下轨平行）。

平行判定：|k_upper - k_lower| < ε（ε=0.001，整理者分析）。

### 4. 有效性判定

- 下轨和上轨均已确认（各至少2个取点）；
- 两条轨线平行（斜率差在容差ε内）；
- 股价在通道内运行（至少1次触下轨反弹、1次触上轨回落），验证通道的有效性；
- 通道宽度（channel_width）应合理，过窄（<1%）可能是噪音，过宽（>50%）可能不是同一趋势（整理者分析，非权威来源）；
- 若股价有效突破上轨（上升通道）或跌破下轨（下降通道），原通道可能失效，需重新画线。

### 5. 攻防逻辑

- 上升通道：
  - 股价触下轨不破→看涨，可介入（防守转攻）；
  - 股价触上轨不过→看跌，可减仓（攻转守）；
  - 股价有效突破上轨→通道加速，可加仓（冲）；
  - 股价有效跌破下轨→通道失效，应出货（防）。
- 下降通道：
  - 股价触上轨不过→看跌，应出货；
  - 股价触下轨不破→可能反弹，可轻仓介入；
  - 股价有效跌破下轨→加速下跌，应坚决出货；
  - 股价有效突破上轨→通道可能反转，关注介入机会。
- 四步攻防（原著第5讲第三节）：攻（触下轨）→守（回踩确认）→冲（突破上轨）→防（触上轨回落）。

### 6. 边界情况

| 情况 | 处理方式 |
|---|---|
| 仅1条轨线确认 | 不构成通道线，标注"轨线不足" |
| 两条轨线不平行（斜率差>ε） | 不构成通道线，标注"轨线不平行" |
| 通道宽度过窄（<1%） | 标注"窄通道，可能为噪音，可靠性低"（整理者分析） |
| 通道宽度过宽（>50%） | 标注"宽通道，可能不是同一趋势"（整理者分析） |
| 股价突破通道后未回归 | 原通道失效，应根据新的取点重新画线（动态调整） |
| 停牌后首日 | 停牌日保留在时间轴上 |
| 除权除息日 | 必须使用前复权数据，否则轨线失真 |
