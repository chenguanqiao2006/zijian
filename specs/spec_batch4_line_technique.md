### 1. 自然语言定义

金线战法即"黄金线战法"的简称。"金线"即"黄金线"，既是主庄苦心经营的"攻防线"，又是主庄步步为营的"生命线"。抓住主庄的黄金线，就等于抓住了主庄的攻防路线图。金线战法的画线基础是黄金柱（或将军柱）：以黄金柱对应价柱的关键价位（实顶/实腰/实底）画线，形成一条水平黄金线，股价回踩黄金线不破即为介入时机。

### 2. 战法构成

- 基因组合：黄金柱（基柱后三日价升量缩，王牌柱之一）+ 黄金线（以黄金柱对应价柱关键价位画的水平线）+ 回踩动作（股价回调触及黄金线并获得支撑）；
- 三要点（第10章）：①金线战法的画线（顺势画线）；②对付强庄的战法（强庄踩顶）；③对付精庄的金线战法（精庄踩腰）；④对付狡庄的战法（狡庄踩脚）；
- 三部曲（第11章）：①基础——找准黄金柱；②核心——跟着主力走；③灵魂——用活黄金线。

### 3. 底层逻辑（从三先规律推演）

- 卖在买先：股价回踩黄金线时，前期获利盘在线上方卖出（有人愿意卖），黄金线附近形成换手。回踩缩量说明卖盘枯竭——"卖"的力量在黄金线上耗尽，买方只需较小承接即可维持价格，故回踩不破是强势信号；
- 价在量先：黄金线价位本身是主力前期认可的价格（黄金柱实顶/实底），价格回到该位置时，主力认为价格合适而承接（买），成交才能达成；若价格跌破黄金线，说明价格已不被主力认可，成交逻辑破坏；
- 庄在散先：黄金柱是主力行为的量柱记录，黄金线是主力攻防路线的轨迹。散户回踩时恐慌卖出，主力却在黄金线上按既定路线接货——回踩不破正是"庄在散先"的直接体现；
- 原著："黄金线既不是用来看的，也不是用来玩的，而是以此为杠杆来撬动市场的，所以它是架住下蹲与起跳的依托。它如同战场上的战壕和掩体。"[抖音转载《伏击涨停》第11章讲座内容，非原著原文，为二次整理资料，仅作线索参考]

### 4. 纯理论准则

有效条件：
- 黄金柱（或将军柱）已确认（基柱后三日价升量缩，见批次1规格卡7）；
- 黄金线已按对应价柱关键价位画出；
- 股价回踩黄金线，实体收盘价不低于线价（虚底刺破无效）；
- 回踩期间成交量相对萎缩（卖盘枯竭，整理者分析，非权威来源）。

失效条件：
- 黄金柱未确认或为假黄金柱（后三日跌破实底）；
- 股价实体收盘价跌破黄金线（有效跌破，非虚底刺破）；
- 回踩时放量下跌（承接失败，整理者分析，非权威来源）。

### 5. 边界情况

| 情况 | 处理方式 |
|---|---|
| 黄金柱基柱为跳空高开（零号） | 以缺口柱（跳空K线）为取点基准，黄金线画法按元帅柱零号规则处理（见批次2元帅柱规格卡） |
| 回踩时上影线刺破但实体未破 | 有效回踩（虚底刺破无效），以实体收盘价为准 |
| 回踩放量 | 标注"放量回踩，承接存疑"，需后续1根K线确认（整理者分析，非权威来源） |
| 黄金线同时为精准线/峰谷线 | 价值增强（重合量线越多价值越高），标注重合线类型 |
| 除权除息日 | 必须使用前复权数据 |
| 停牌后首日 | 停牌日保留在窗口内，回踩确认以复牌后K线为准 |

### 1. 自然语言定义

强庄踩顶是金线战法三庄型之一：对付强庄，以黄金柱所对应的价柱实顶（虚顶）画黄金线。因为黄金柱确认时基柱后三日价升量缩，其对应价柱实顶即成为强势主力攻防的平衡线。股价回踩该实顶黄金线而不破，即确认强庄仍在按攻防路线运作，回踩为介入良机。

### 2. 战法构成

- 基因组合：黄金柱 + 实顶黄金线（以黄金柱对应价柱实顶/虚顶画线）+ 回踩不破实顶；
- 画线取点：黄金柱对应价柱的实顶（max(O,C)，优先）或虚顶（H，参考），取实后取虚；
- 原著原文："对付强庄的金线战法：就是以黄金柱所对应的价柱实顶画黄金线，以测算或确认主力攻防路线。……黄金柱对应的价柱实顶就成了强势主力攻防的平衡线，我们只要以实顶画线，一眼就能测算这个主力的实力和动机。"[股海明灯官网王子语录，官方论坛文献]

### 3. 底层逻辑（从三先规律推演）

- 卖在买先：实顶是主力前次进攻的"终点价位"，回踩至此，前期追高者的卖出压力在此释放。回踩缩量说明卖盘在实顶上方已枯竭，主力无需大量买盘即可托住价格；
- 价在量先：强庄操盘的特征是价格节奏清晰——回踩精准触及实顶即止跌，说明该价位是主力预设的承接价（"价格合适才成交"），价格不破实顶则成交逻辑未破坏；
- 庄在散先：只有高度控盘的强庄，才能把回踩控制得如此精准（实顶处止跌）。回踩不破实顶=主力仍在场并主动防守，是"庄在散先"的最直接证据。

### 4. 纯理论准则

有效条件：
- 黄金柱已确认（后三日价升量缩）；
- 实顶黄金线已画出；
- 股价回踩实顶线，实体收盘价不低于线价；
- 回踩缩量（整理者分析，非权威来源）。

失效条件：
- 黄金柱未确认/假黄金柱；
- 实体收盘价跌破实顶线（有效跌破）；

### 1. 自然语言定义

黄金双线是依托黄金柱设置的上下两条黄金线：上线主攻，下线主守，形成一个攻守兼备、进退自如的"攻防双赢系统"。上线（保护线）是主力保护自己的，所有打压与A1线不即不离；下线（打击线）是主力打击对手的，长腿踩线最低点回踩下线即迅速收回。上破加仓、下破止损、线间高抛低吸。

### 2. 战法构成

- 基因组合：黄金柱 + 上线A1（以黄金柱自身实顶/实底/虚底画线）+ 下线A2（以黄金柱后三日的实底或虚底画线）+ 线间运行行为；
- 设置秘诀（原著第二节）：先找实来后画虚；上线确认看黄金价柱实体；下线确认看长腿踩线的底端；
- 双线画法原则："双线画法有预期，先找实来后画虚；上线坚守为自己，下线攻击吓对手"（股海明灯论坛顺口溜，为二次整理资料，仅作线索参考）；
- 上下两线之间形成"伏击圈"，设伏击圈方法为观察主力左侧惯用手法，选择虚线介入或实线介入。

### 3. 底层逻辑（从三先规律推演）

- 卖在买先：上线之下、下线之上的"双线区间"是换手区——股价在上线附近时前期获利盘卖出，在下线附近时恐慌盘卖出。卖盘在区间内被分批消化，为后续拉升减轻抛压；
- 价在量先：双线是主力预设的两个价格档位：上线是主力"保护自己"的价格（跌破则主力筹码受损），下线是主力"打击对手"的价格（击穿则洗出散户）。价格在两档之间波动时，成交持续发生（高抛低吸）；
- 庄在散先：散户只看到一条线（通常只设一个止损位），主力却用两条线完成攻防：在上线接回筹码（守），在下线吓出浮筹（攻）。双线区间是主力主导的"战场"，散户在区间内被反复清洗。

### 1. 自然语言定义

黄金十字（黄金十字架）是以黄金柱为"身躯"、以黄金线/精准线为"臂膀"（横轴）、以过黄金柱的竖线为纵轴的十字结构，左右形成"左支右撑"格局。核心口诀："十字顶底换，牛股要上天"；连续三个逐步递升的黄金十字架后一般有30%涨幅。

### 2. 战法构成

- 基因组合：黄金柱（身躯/核心）+ 黄金线或精准线（横轴/臂膀）+ 过黄金柱的竖线（纵轴）+ 左支右撑格局（左侧有支撑、右侧有支撑的对称结构）；
- 三特点（原著/特训班）：
  ① 黄金十字架是可以提前预判的（第一个十字架有坚固基础、第二个有良好雏形，即可在其突破上级平衡线时择机介入）；
  ② 黄金十字架是可以预测涨幅的（连续三个逐步递升的黄金十字架，其后一般有30%涨幅）；
  ③ 黄金十字架的预判一定要结合其所在位置（位置决定性质）；
- 分时十字架：日K线有十字架（峰谷线、峰顶谷底），分时量波有十字线（尖底线、浪尖浪底）——本规格卡只处理日线层级。

### 3. 底层逻辑（从三先规律推演）

- 卖在买先：十字架的横轴（黄金线/精准线）汇聚了多个价位重合点，说明该价位发生过密集换手（多轮买卖在此成交），卖盘在此反复释放后趋于枯竭，横轴成为"卖无可卖"的支撑；
- 价在量先：竖轴过黄金柱——黄金柱是主力成本价位，横竖交叉点即"主力成本+市场共识价位"的时空交汇点，价格回到此点即触发主力承接（价定量成）；
- 庄在散先：左支右撑的对称结构是主力刻意经营的结果（左支=左侧量线支撑，右撑=右侧量线支撑）。散户难以同时识别横竖两条线，主力却在十字架处完成洗盘与接力——"十字顶底换"实为主力主导的顶底互换工程；
- 原著：十字架战法业绩比其他战法高两成左右，但应用表象者多、抓住本质者少（本质=黄金柱核心+精准线质量）。[《黑马王子操盘手记(3)》，清华大学出版社2016年版]

### 4. 纯理论准则

有效条件：
- 黄金柱已确认（十字架身躯）；
- 横轴为黄金线或精准线（臂膀），且至少有3个价位重合点（精准线口径见核实结论8）；
- 竖轴过黄金柱形成十字；
- 左右形成左支右撑格局；
- 股价回踩十字架横轴不破（介入时机："回踩峰顶线，倍量就拉升"）。

失效条件：
- 黄金柱未确认/假黄金柱；
- 横轴无精准线支撑（仅普通平衡线，质量不足）；
- 十字架左支右撑格局破坏（一侧支撑失效）；
- 实体收盘价跌破横轴。

### 1. 自然语言定义

一剑封喉：用"距今最近的波峰右侧最凸出的大阴实顶"与"距今最近的凹底左侧最凸出的大阴实顶"连线，形成一条下行斜衡线，这条下行斜衡线与底部平衡线相交的地方，就是"一剑封喉"（即介入点）。强调"凸出"而非"突出"；底部平衡线优选精准线或黄金线（"精准线上一剑封喉"/"黄金线上一剑封喉"）。

### 2. 战法构成

- 基因组合：两个大阴实顶（波峰右侧最凸出 + 凹底左侧最凸出）+ 下行斜衡线（封喉线）+ 底部平衡线（优选精准线/黄金线）+ 交叉点（封喉点）；
- 三要素（原著第二节）：
  ① 两个大阴实顶的"凸出"性（凸出=明显突出于周围K线的大阴线，取其实顶）；
  ② 下行斜衡线方向向下（通常就是下行的太极线）；
  ③ 底部平衡线优选精准线或黄金线；
- 封喉线性质：股价沿斜衡线下行，越到下方下跌动能越小、斜衡线阻力越小；而越接近重要平衡线，所遇支撑越大——因此斜衡线与平衡线交叉处往往有中到大阳出现。

### 3. 底层逻辑（从三先规律推演）

- 卖在买先：大阴实顶是前期套牢盘的密集卖出价位。下行斜衡线连接两个大阴实顶，勾勒出"卖压递减"的轨迹——股价每跌至新低，套牢盘已在前一轮卖出中消耗，卖盘逐步枯竭；
- 价在量先：底部平衡线（尤其是精准线/黄金线）是主力认可的价格带。价格跌至斜衡线与平衡线交叉处时，"卖压递减"与"支撑递增"双向收敛——价格在此达成新的均衡，成交放量（中到大阳）即多空力量逆转的价量信号；
- 庄在散先：大阴是主力刻意打压的痕迹（长阴短柱性质），下行斜衡线是主力"挖坑"的轨迹，底部平衡线是主力预设的承接价位。散户在下跌中割肉离场，主力却在交叉处完成最后收集，随后中到大阳拉升——"一剑封喉"即主力收网动作。

### 4. 纯理论准则

有效条件：
- 两个大阴实顶均已确认（波峰右侧 + 凹底左侧，最凸出者）；
- 下行斜衡线已画出；
- 底部平衡线为精准线或黄金线（优选）；
- 股价运行至交叉处出现中到大阳（确认收网，整理者分析：阳线实体涨幅≥3%作为工程化阈值，非权威来源）；
- 交叉处附近有涨停基因（如长阳矮柱、卧底将军）则增强（原著第四节约束，拾荒网转载，二次整理，仅作线索参考）。

失效条件：
- 大阴实顶取点错误（非"凸出"而是"突出"）；
- 底部平衡线为普通线（非精准线/黄金线，质量不足）；
- 股价运行至交叉处放量下跌（封喉失败，整理者分析）；
- 交叉处阳线实体涨幅过小（<3%，整理者分析阈值）。

## 规格卡 8：平斜交叉

| effective_confirmation | 平衡线确认 + 斜衡线确认 + 交叉点出现；叉上/叉下方向由交叉后K线收盘确认 |
| dependencies | 平衡线（spec_batch3_price_line.md）、斜衡线（spec_batch3_price_line.md）、位置判定（spec_global_rules.md） |

### 1. 自然语言定义

平斜交叉特指平衡线与斜衡线的交叉间隔（结构）。平衡线是对股价涨跌幅度的刻画（静态过程，体现高度和幅度）；斜衡线是对股价涨跌速度的刻画（动态过程，体现方向趋势）。二者结合形成"平斜交叉"结构，互补互助，将股价涨跌的幅度与速度、时间与空间展示出来，运用得当其时间误差仅为几个小时。口诀："叉上看涨，叉下看跌"。

### 2. 战法构成

- 基因组合：一条水平平衡线 + 一条斜衡线（上行或下行）+ 交叉点（临界点）；
- 平衡线取点：按批次3规格卡3（上行找实顶，下行找实底，实点靠整点，无点找密点）；
- 斜衡线取点：按批次3规格卡4（两个同方向拐点连线，或太极线）；
- 平斜交叉的本质（原著）：动态平衡——平衡过程由平衡线和斜衡线的动态建构来刻画和调整；
- 力学原理（原著第三节）：斜衡线对股价的阻力随价格下行递减（越到下方动能越小），平衡线的支撑随价格逼近递增，交叉处形成"阻力极小值+支撑极大值"的力学收敛点。

### 3. 底层逻辑（从三先规律推演）

- 卖在买先：斜衡线（尤其下行斜衡线）勾画的是卖压递减的轨迹——股价沿线下行，每至新低都有一批套牢盘卖出，越到下方卖盘越枯竭；交叉处是卖盘释放殆尽的位置；
- 价在量先：平衡线是"价格均衡点"（多空暂时平衡），斜衡线是"价格运动轨迹"（方向与速度）。交叉处=均衡价格与运动轨迹的汇合，价格在此被双重确认，成交（中到大阳）因价格合适而放大——价定量成；
- 庄在散先：平斜交叉是主力用两条线预设的"伏击点"。散户只见价格涨跌（幅度），不见速度与时间的动态结构（斜衡线），更看不到交叉的时空意义。主力在交叉处收网，散户在交叉处追涨或割肉——"择机上下"即主力主导的时机选择；
- 原著：将平衡线和斜衡线结合起来，就能互补互助，将股价涨跌的幅度与速度、时间和空间展示在我们面前，"只要运用得当，其时间误差仅为几个小时"。

### 4. 纯理论准则

有效条件：
- 平衡线已确认（按批次3规则）；
- 斜衡线已确认（按批次3规则）；
- 交叉点已出现（两线交点，交叉日在斜衡线最新取点确认日之后）；
- 叉上（股价在交叉点上方）：看涨，回踩不破交叉价位可介入；
- 叉下（股价在交叉点下方）：看跌，反抽不过交叉价位应回避。

失效条件：
- 平衡线或斜衡线未确认；
- 交叉点位置在斜衡线最新取点之前（未来函数违规，不允许）；
- 叉下时放量上攻突破交叉价位（趋势逆转，需重新评估，整理者分析）。

### 1. 自然语言定义

回踩精准线是一套由涨停基因组合而成的涨停密码，由"回踩"这个动作和"精准线"这个杠杆有机组合而成。精准线由3个以上的关键点位或价位精准重合而成的一条平衡线（《涨停密码》口径；《量线捉涨停》水平精准线为两个以上、倾斜精准线为三个以上，两书口径差异见核实结论8）。如果精准线和黄金线重合就是精准黄金线，如果精准线和峰谷线重合就是精准峰谷线——重合的量线越多，精准线的价值就越高。

### 2. 战法构成

- 基因组合：精准线（3个以上关键点位精准重合）+ 回踩动作（股价回调精准踩线获支撑）+ 量线重合增强（精准黄金线/精准峰谷线）；
- 精准线取点：按批次3规格卡6（水平精准线≥2个取点/倾斜精准线≥3个取点，容差δ_h=0.01元）；
- 回踩定义：股价从线上方回调，最低价（或实体底）精准触及精准线价位；
- 口诀："回踩精准线，涨停在眼前；精准线上阳，后市必大涨"（股海明灯论坛流传，为二次整理资料，仅作线索参考）。

### 3. 底层逻辑（从三先规律推演）

- 卖在买先：精准线由3个以上价位重合而成，说明该价位发生过多次密集成交——每一次触及都伴随一轮卖出与承接，卖盘在该价位反复释放后趋于枯竭；回踩至此，卖无可卖；
- 价在量先：精准线价位是主力反复"精确操盘"留下的指纹（多价位精确重合），说明该价位是主力预设的承接价。价格回踩到精准线=价格回到主力认可的区间，成交达成（价定量成）；
- 庄在散先：只有高度控盘的主力才能让股价反复精确地触及同一价位——精准线是主力操盘指纹，回踩是主力洗盘动作。散户在回踩中恐慌卖出，主力在精准线处精确接货；重合的量线越多（精准黄金线/精准峰谷线），主力预设的价格防线越完整，价值越高。

### 4. 纯理论准则

有效条件：
- 精准线已确认（按批次3规格卡6，取点满足、容差内重合）；
- 股价回踩精准线，实体收盘价不低于线价（或最低价精准触线）；
- 回踩缩量（整理者分析）；
- 精准线与黄金线/峰谷线重合则增强。

失效条件：
- 精准线未确认（取点不足或重合超容差）；
- 实体收盘价跌破精准线（有效跌破）；
- 回踩放量（承接失败，整理者分析）。

### 1. 自然语言定义

站稳凹峰：股价经过一波上涨后回调，形成"凹"字结构（左侧上攻+中间回调+右侧再上攻），凹口的左侧高点连线即为"凹峰"（峰顶线）。股价再次上攻突破凹峰峰顶线后回踩不破（站稳），确认凹峰被有效攻占（顶底互换完成），即将上攻。

### 2. 战法构成

- 基因组合：凹字结构（左侧上攻+回调+右侧再上攻）+ 凹尖峰（凹口左侧高点）+ 凹尖峰精准线（以凹尖峰大阴实顶画水平线，与其附近架柱有3个以上契合点）+ 突破峰顶线 + 回踩站稳；
- 凹尖峰三特征（原著/特训班）：
  ① 凹尖峰的架柱往往是当前最大的量柱（高量柱）；
  ② 凹尖峰的架柱往往是主力前期的假阴真阳；
  ③ 以凹尖峰的大阴实顶画水平线，往往与其附近的架柱有三个以上的契合点，形成凹尖峰精准线；
- 站稳定义：突破凹峰峰顶线后，回踩该线实体不破（过峰保顶，顶底撑压互换）。

### 3. 底层逻辑（从三先规律推演）

- 卖在买先：凹峰处（左侧高点）是前期获利盘与套牢盘的卖出密集区。第一次上攻遇阻回落（卖压释放），回调形成"凹"底；第二次上攻突破凹峰时，前期卖压已大部分消化，突破后回踩不破=卖盘在该价位彻底枯竭；
- 价在量先：凹尖峰的大阴实顶是主力"试盘"留下的价格痕迹（架柱为假阴真阳——阴线形态但实际是吸筹）。大阴实顶画出的精准线是主力预设的攻防线，价格突破该线=价格越过主力预设障碍，回踩站稳=价格在主力认可的新区间成交（价定量成）；
- 庄在散先：凹字结构是主力"挖坑-填坑"的操盘轨迹：左侧上攻是试盘（架柱放量/假阴真阳），回调是洗盘（散户割肉），右侧突破是收网。凹尖峰精准线的3个以上契合点证明主力精确控盘——散户看到"回调"，主力看到"蓄势"，站稳凹峰即主力主导的顶底互换完成。

### 4. 纯理论准则

有效条件：
- 凹字结构完整（左侧上攻+回调+右侧再上攻）；
- 凹尖峰架柱为高量柱或假阴真阳（三特征至少满足前两条）；
- 凹尖峰精准线形成（大阴实顶水平线有3个以上契合点）；
- 股价突破凹峰峰顶线；
- 突破后回踩峰顶线实体不破（站稳确认）。

失效条件：
- 凹尖峰无精准线支撑（契合点<3个）；
- 突破凹峰后回踩实体跌破峰顶线（顶底互换失败）；
- 突破时放量滞涨（上攻动能不足，整理者分析）。

### 5. 边界情况
