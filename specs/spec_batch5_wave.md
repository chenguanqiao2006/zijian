### 元数据

| 字段 | 值 |

| dependencies | 无（基础描述层，被所有量波规格卡引用） |

### 1. 自然语言定义

量波七大基元是分时量波的七个基本构成元素，是描述分时图中价格线（天线）与均价线（人线）形态、方向、力度、幅度、时段、间距、能量的最小语义单元。七大基元分别为：波形、波向、波势、波幅、波段、波距、波能。任何分时量波形态都可拆解为这七个基元的组合。

### 2. 输入数据

| 变量名 | 数据含义 | 数据类型 | 数据来源 |
|---|---|---|---|
| antenna[t] | 第t分钟天线（价格线）收盘价 | float | 分时行情 |
| human[t] | 第t分钟人线（均价线）值 | float | 分时行情（累计成交额/累计成交量） |
| volume[t] | 第t分钟成交量 | int | 分时行情 |
| ground[t] | 第t分钟地线（昨收价/零轴） | float | 日线昨收 |
| t | 当前分钟序号（9:30=1, ..., 15:00=240） | int | 时间戳 |

### 3. 精确计算公式

- 波形（wave_shape）：天线在连续N分钟内的平滑度分类。
  平滑度 S = 1 - (Σ|antenna[i] - antenna[i-1] - mean_slope|) / (N × price_range)
  （S越接近1越平滑，越接近0越尖锐。阈值为整理者分析，非权威来源）
- 波向（wave_direction）：sign(antenna[t] - antenna[t-N])，N为观察窗口（默认5分钟，整理者分析）
- 波势（wave_momentum）：(antenna[t] - antenna[t-N]) / N，单位价格/分钟
- 波幅（wave_amplitude）：max(antenna[t-N..t]) - min(antenna[t-N..t])
- 波段（wave_segment）：连续同方向波的起止分钟区间 [t_start, t_end]
- 波距（wave_distance）：|antenna[t] - human[t]|，即天线与人线的垂直距离（以"格"为单位，1格=分时图固定价格刻度，整理者分析）
- 波能（wave_energy）：Σ(volume[i] × |antenna[i] - antenna[i-1]|)，i∈[t-N, t]，量价乘积之和

### 4. 判定条件（布尔表达式）

- 波形判定：
  平滑波：S ≥ 0.7（整理者分析阈值）
  尖角波：S < 0.3 且存在 |antenna[i] - antenna[i-1]| > 2×mean_abs_change
  圆角波：0.3 ≤ S < 0.7
- 波向判定：
  向上：wave_direction > 0
  向下：wave_direction < 0
  横盘：wave_direction == 0（容差±0.01元，整理者分析）
- 波势判定：
  强势：|wave_momentum| ≥ 0.05元/分钟（整理者分析）
  弱势：|wave_momentum| < 0.05元/分钟
- 波幅判定：
  大幅：wave_amplitude ≥ 3% × 昨收价（整理者分析）
  小幅：wave_amplitude < 1% × 昨收价
- 波距判定：
  大偏离：wave_distance ≥ 4.5格（恐龙波标准，已核实）
  小偏离：wave_distance ≤ 1.5格（股海三龙标准，二次整理）
- 波能判定：
  放量：wave_energy[t] ≥ 1.5 × wave_energy[t-N..t-1]均值（整理者分析）
  缩量：wave_energy[t] ≤ 0.7 × 均值

### 5. 边界情况

| 情况 | 处理方式 |
|---|---|
| 开盘集合竞价（9:15-9:25） | 不计入分时基元计算，从9:30第1分钟开始 |
| 午间休市（11:30-13:00） | 波段计算跨午休时断开，上午/下午分别计段 |
| 停牌复牌 | 复牌首分钟数据可能异常跳空，标注"复牌跳空"，波幅/波势计算需人工复核 |
| 一字涨停/跌停 | 天线=人线=涨跌停价，波距=0，波形无意义，标注"一字板，基元不适用" |
| 尾盘集合竞价（14:57-15:00） | 尾盘3分钟为集合竞价，天线可能跳变，标注"尾盘竞价" |
| 数据缺失（某分钟无成交） | antenna[t]=antenna[t-1]，volume[t]=0，波能贡献为0 |

### 1. 自然语言定义（原著版本B，经官方论坛原文确认）

量波八大要素是分时图中用于研判量波的八个核心观察对象：**黄线、白线、力柱、量柱、天线、地线、人线、警线**。八大要素是量波研判的"仪表盘"——通过观察八要素的相对位置、形态变化和配合关系，判断盘中多空力量对比。

股海明灯论坛原文直接引用："'量波'的'研判系统'，由'黄线、白线、力柱、量柱'和'天线、地线、人线、警线'这'八大要素'组合而成。"（官方论坛文献）

八要素"2个为组4组并齐"：黄线与白线为一组（分时双线）、力柱与量柱为一组（量能双柱）、天线与人线为一组（价格双线）、地线与警线为一组（基准双线），彼此相互制约又相互依赖。

版本A（天线/人线/地线/力柱/零轴/波峰/波谷/警线）为早期整理版，经核实为误传——"零轴"实为"地线"的别称，"波峰/波谷"不在原著八要素清单中，降级为附录对照。

### 3. 精确计算公式（原著版本B）

- 黄线（yellow_line）：个股分时中 yellow_line[t] = human_line[t] = 均价线（VWAP）；大盘分时中 yellow_line[t] = 不加权平均指数
- 白线（white_line）：个股分时中 white_line[t] = antenna[t] = 当前分钟收盘价（价格线）；大盘分时中 white_line[t] = 加权指数
- 人线（human_line）：human_line[t] = Σ(amount[i]) / Σ(volume[i])，i∈[1, t]，即开盘至当前分钟的累计成交额除以累计成交量（VWAP）
- 天线（antenna）：antenna[t] = 当前分钟收盘价（即white_line）
- 地线（ground_line）：ground_line = 昨收价（固定值，当日不变，又称"零轴"）
- 力柱（force_bar）：force_bar[t] = 主动买入量 - 主动卖出量（正为红柱，负为绿柱，数据来源为盘口逐笔成交，整理者分析）
- 量柱（volume_bar）：volume_bar[t] = 第t分钟成交量
- 警线（alert_line）：由量线维度移植的关键价位（如黄金线、精准线、峰顶线），或人工设定的涨跌停价、止损位

### 4. 判定条件（布尔表达式，原著版本B）

- 正三维：antenna[t] > human_line[t] > ground_line（天线在人线上方，人线在地线上方）→ 强势
- 倒三维：antenna[t] < human_line[t] < ground_line → 弱势
- 黄白双线关系（大盘分时）：white_line > yellow_line → 权重股领涨；white_line < yellow_line → 中小盘领涨（整理者分析）
- 天线人线缠绕：|antenna[t] - human_line[t]| ≤ 0.5格 且持续≥10分钟（整理者分析阈值）→ 方向不明
- 天线上方开口：antenna[t] - human_line[t] ≥ 1.5格 且差值持续扩大 → 强势持股
- 天线下方开口：human_line[t] - antenna[t] ≥ 1.5格 且差值持续扩大 → 弱势回避
- 力柱配合：force_bar[t] > 0 且 antenna[t] 上升 → 真涨；force_bar[t] < 0 且 antenna[t] 上升 → 假涨（整理者分析）
- 量柱配合：volume_bar[t] 放大且 antenna[t] 上升 → 量价齐升；volume_bar[t] 萎缩且 antenna[t] 上升 → 价升量缩（筹码锁定或诱多，需结合位置判断）

### 1. 自然语言定义

- 人线制导成立：guidance == true 且 人线偏离度 ≤ 2%（整理者分析阈值）

### 3. 精确计算公式

- 出货波判定：

### 1. 自然语言定义

恐龙波是一种近乎直上直下的分时量波形态（"直升直降"），因形态恐怖如侏罗纪恐龙而得名。恐龙波的市场含义取决于位置：低位恐龙波多为洗盘吸筹，可做"高抛低吸"或"盘中T+0"；高位恐龙波谨防"做头"或"出货"。量化标准：天线与人线偏离达到4.5格（已核实）。

### 2. 输入数据

| 变量名 | 数据含义 | 数据类型 | 数据来源 |

### 3. 精确计算公式

- 天线人线偏离格数：deviation_grid = |antenna[t] - human_line[t]| / grid_size
- 直上直下判定：存在连续≤3分钟内 antenna 变化幅度 ≥ 3% × 昨收价（整理者分析阈值）
- 恐龙波核心条件：deviation_grid ≥ 4.5 AND 存在直上直下波动
- 低位恐龙：position == low AND deviation_grid ≥ 4.5
- 高位恐龙：position == high AND deviation_grid ≥ 4.5

### 4. 判定条件（布尔表达式）

- 恐龙波成立：deviation_grid ≥ 4.5 AND (max(antenna[t-2..t]) - min(antenna[t-2..t])) ≥ 0.03 × ground_line
- 低位恐龙（洗盘吸筹型）：恐龙波成立 AND position == low
- 高位恐龙（做头出货型）：恐龙波成立 AND position == high
- 中位恐龙：恐龙波成立 AND position == mid（方向不明，观望）

### 5. 边界情况

### 1. 自然语言定义

飘龙是一种波形圆滑、轻松向上飘逸的分时量波形态。核心特征：过峰（突破前期高点）、"价升量缩"背反（价格上升但成交量萎缩，说明筹码锁定良好）、人线登梯（人线稳步上行如登梯）、天线沿人线（天线紧贴人线上行，偏离小）。飘龙与恐龙波相对——恐龙是尖角直上直下，飘龙是圆角圆滑上行。口诀："飘龙过峰，价升量缩，背反必涨。"

### 2. 输入数据

| 变量名 | 数据含义 | 数据类型 | 数据来源 |

| antenna[t] | 天线 | float | 分时行情 |

### 3. 精确计算公式

- 圆滑波形：smoothness ≥ 0.7（整理者分析阈值，同七大基元）

- 人线登梯：human_slope[t] > 0 且 连续≥10分钟 human_line 单调不减（允许≤0.1%微幅回调，整理者分析）
- 天线沿人线：|antenna[t] - human_line[t]| ≤ 1.5格 且 antenna[t] ≥ human_line[t]
- 价升量缩：antenna[t] > antenna[t-10] AND volume[t] < avg(volume[t-10..t-1])
- 过峰：antenna[t] > recent_peak（近期分时高点）
- 飘龙成立：圆滑 AND 人线登梯 AND 天线沿人线 AND 价升量缩

### 4. 判定条件（布尔表达式）

- 飘龙成立：smoothness≥0.7 AND human_monotonic_up(10min) AND deviation≤1.5grid AND price_up AND volume_shrink

### 1. 自然语言定义

必守三要领是《量波逮涨停》第17章提出的三条量波操作纪律，是量波逮涨停的"底线原则"：

- **要领一：日象为王（根本）——不要迷信量波**。量波是分时维度的表象，不能脱离日线大方向（日象）孤立判断。任何分时量波信号都必须先经过日线方向的校验——日线向上时的分时强势才是真强势，日线向下时的分时强势可能是诱多。"日象"包含日线的趋势方向、量柱形态、量线位置等综合景象。
- **要领二：人线为王（核心）——不要单看量波**。分时图中不能只看天线（价格线）的涨跌，必须以人线（均价线/VWAP）为核心判断。人线是分时多空成本线，天线围绕人线波动，人线方向制导天线方向。单看天线容易被瞬时价格波动误导。
- **要领三：量变为王（准绳）——不要误读量波**。成交量的变化是判断量波真伪的准绳。价升量缩与价升量增含义完全不同，必须结合量能变化来解读量波形态，避免误读。
- **第四节 重在综合性**：量波逮涨停必须综合日象、人线、量变三个维度，不可偏废。

注：必守三要领与第4章"三导定律"（日向为王/人线为王/力量为王）表述相近但措辞不同——三导定律是"运行规律"（传导律/制导律/反导律），必守三要领是"操作纪律"（根本/核心/准绳），二者互为表里。[来源：浙江工商大学图书馆馆藏目录+东北林业大学图书馆馆藏目录交叉确认第17章四节标题（高校图书馆OPAC系统，权威文献来源）]

补充：三维互动操作要领（非第17章原文，出自本书前言及经济日报出版社新书发布会演讲）——①标的要明确，用量柱选股；②标准要精确，用量线选价；③标杆要准确，用量波选时。此为"量柱选股→量线选价→量波选时"三维互动的操作化表达，与必守三要领（日象/人线/量变）是不同层面的概念，本规格卡将其作为辅助检查项。

### 3. 精确计算公式

- 要领一（日象为王）检查：daily_trend 与分时波向一致
  daily_consistency = 1 if (daily_trend==up AND wave_direction≥0) OR (daily_trend==down AND wave_direction≤0) else 0
  （日象校验：分时信号必须与日线大方向一致）
- 要领二（人线为王）检查：以人线为核心，天线不偏离人线过远
  human_central = (|antenna[t] - human_line[t]| / human_line[t]) ≤ 3%（整理者分析阈值）
  AND human_slope[t] 与天线方向一致
- 要领三（量变为王）检查：量能变化与价格变化的配合关系
  volume_price_match = (price_up AND volume_up) OR (price_up AND volume_shrink AND lock_chips) OR (price_down AND volume_up)
  （量价配合逻辑，具体判定见各量波规格卡）
- 三要领全满足：daily_consistency AND human_central AND volume_price_match AND wave_signal_valid

### 4. 判定条件（布尔表达式）

- 可操作：daily_consistency AND human_central AND volume_price_match AND wave_signal_valid
- 不可操作（日象不符）：NOT daily_consistency → 标注"日象不符，不要迷信量波"
- 不可操作（偏离人线）：NOT human_central → 标注"天线偏离人线过远，不要单看量波"
- 不可操作（量价背离）：NOT volume_price_match → 标注"量能不配合，不要误读量波"

### 1. 自然语言定义

早盘定调期是指开盘后一段时间内（通常为9:30-10:00，开盘后30分钟），通过观察分时量波的八要素和三导定律，判断当日多空基调的时段。早盘是全天交投最活跃的时段，主力真实意图往往在早盘暴露，早盘定调对全天操作具有指导意义。

声明：原著《量波逮涨停》目录中未发现以"早盘定调期"命名的独立章节【未能核实原著明确定义】。本规格卡为整理者基于量波看盘方法论（八大要素、三导定律、四步攻防）的工程化归纳，标注【整理者分析，非权威来源】。通用技术分析中有"开盘15分钟定基调""开盘半小时定全天"的经验表述，但非量学原著内容。

### 2. 输入数据

| 变量名 | 数据含义 | 数据类型 | 数据来源 |
|---|---|---|---|
| antenna[9:30-10:00] | 早盘30分钟天线序列 | float[] | 分时行情 |
| human_line[9:30-10:00] | 早盘30分钟人线序列 | float[] | 分时行情 |
| volume[9:30-10:00] | 早盘30分钟成交量 | int[] | 分时行情 |
| ground_line | 地线（昨收） | float | 日线昨收 |
| opening_price | 开盘价 | float | 分时行情 |

### 3. 精确计算公式

- 早盘涨跌幅：open_return = (antenna[10:00] - ground_line) / ground_line × 100%
- 早盘人线斜率：human_slope_open = (human[10:00] - human[9:30]) / 30
- 早盘量比：volume_ratio_open = avg(volume[9:30-10:00]) / avg(volume[昨日同时段])（整理者分析）
- 早盘三维状态：
  强势：antenna[10:00] > human[10:00] > ground_line AND open_return > 0
  弱势：antenna[10:00] < human[10:00] < ground_line AND open_return < 0
  震荡：其他情况
- 早盘基调判定：
  高开高走：opening_price > ground_line AND antenna[10:00] > opening_price AND human_slope_open > 0
  高开低走：opening_price > ground_line AND antenna[10:00] < opening_price
  低开高走：opening_price < ground_line AND antenna[10:00] > opening_price AND human_slope_open > 0
  低开低走：opening_price < ground_line AND antenna[10:00] < opening_price

### 4. 判定条件（布尔表达式）

- 强势基调：strong_open AND volume_ratio_open ≥ 1.2（放量确认，整理者分析）
- 弱势基调：weak_open AND volume_ratio_open ≥ 1.2
- 震荡基调：NOT strong_open AND NOT weak_open
- 诱多警示：高开低走 AND volume_ratio_open ≥ 1.5（放量高开低走，整理者分析）

| 早盘无量（量比<0.5） | 标注"早盘无量，基调不明，观望" |

### 通用约束

1. 分时零未来函数：所有分时信号以"当前分钟收盘价"为确认点，不得使用当日收盘价（15:00）反推盘中信号；允许使用最近N分钟数据，不得使用未来分钟数据。
2. 日线-分时关系：日线信号（量柱/量线）确定大方向，在T-1日收盘后确认；分时信号（量波）确定买卖点，在当日盘中某分钟确认。两者构成"日线定方向、分时定时点"的二维决策。
3. 原著与整理者区分：七大基元/八大要素/三导定律/恐龙/飘龙/三龙/必守三要领来自原著第2-4章、第9-11章、第17章，标注原著出处；早盘定调期与四种典型波形（启动/洗盘/拉升/出货命名）为整理者归纳，标注【整理者分析，非权威来源】；三龙精确量化标准标注【未能核实完整原文】。
