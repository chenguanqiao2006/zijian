## 十二字令原著原文核实

经清华大学出版社前言+新浪财经2012年转载+赢家财富网+拾荒网+豆丁网+股海明灯论坛多源交叉确认，十二字令原文为：

"阳胜进，阴胜出；小倍阳，大胆入。"

清华大学出版社前言原文："量学的十二字令'阳胜进，阴胜出。小倍阳，大胆入'，看似简单，但却蕴含着深邃的股市哲学思想，概括了量学经典的实战技巧，是一个纲领性的东西。"

原著补充要点（经掌阅精选+清华大学出版社前言核实）：
- "阳胜进"指"初阳胜阴可进"；"阴胜出"指"初阴胜阳可出"
- "阳胜"或"阴胜"特指"双向胜"，单向胜时"最好还是看一阵（观望）"
- "下降途中的第一个阳胜，能进吗？不能！因为'位置决定性质'"
- "第一个小倍阳往往是试探，第二个小倍阳多数是试攻，第三个小倍阳..."
- 小倍阳量能范围：原著仅说"高一倍左右（不要高出许多）"，未给出明确量化上下限【未能核实】。本规格卡采用1.9 ≤ V比 ≤ 3.0（下限1.9与批次1倍量柱一致，上限3.0为整理者分析，非权威来源）

## 规格卡 1：阳胜柱

### 元数据

| 字段 | 值 |

| effective_confirmation | T日收盘后确认（当日确认） |

### 1. 自然语言定义

阳胜柱是指当前柱的价柱和量柱双双严格胜过其左侧最近阴柱的形态。原著原文："所谓'阳胜柱'，就是量柱和价柱双向胜过其左侧最近的阴柱。"（新浪财经2012年《伏击涨停的王牌》转载原著；股海明灯论坛王子语录）。十二字令中"阳胜进"即指阳胜柱出现时可考虑介入，但原著强调"初阳胜阴可进"，且"位置决定性质"——下降途中的第一个阳胜不能进。[《伏击涨停》（修订升级版）第3章第二节，张得一著，清华大学出版社2020年版]

### 2. 输入数据

| 变量名 | 数据含义 | 数据类型 | 数据来源 |
|---|---|---|---|
| C[t] | 当日收盘价 | float | 日线行情 |
| O[t] | 当日开盘价 | float | 日线行情 |
| V[t] | 当日成交量 | int | 日线行情 |
| C[left_ying] | 左侧最近阴柱的收盘价 | float | 日线行情（向左遍历） |
| V[left_ying] | 左侧最近阴柱的成交量 | int | 日线行情（向左遍历） |
| C[t-1] | 前一日收盘价 | float | 日线行情 |

### 3. 精确计算公式

左侧最近阴柱确定规则：
- 从T-1日向左遍历，取第一个满足 C[day] < O[day] 的交易日作为 left_ying
- 遍历仅使用T-1日及之前数据（零未来函数）

阳胜柱判定：
- 价胜：C[t] > C[left_ying]（严格大于）
- 量胜：V[t] > V[left_ying]（严格大于）
- 双向胜：价胜 AND 量胜

注：本卡与批次2 spec_batch2_ace_pillar.md 将军柱规格卡中"阳胜柱条件"完全一致（严格大于，非大于等于）。

### 4. 判定条件（布尔表达式）

初胜判断（原著"初阳胜阴可进"）：
- 当前阳柱之前需有至少一根阴柱（即left_ying存在，且left_ying与T日之间可有阳柱，但left_ying是向左遍历第一个阴柱）
- "初胜"指下跌/调整后的首次阳胜，非连续阳胜后的"极盛"状态

极盛判断（原著"极盛则反向操作，阳盛出，阴盛进"）：
- 若T日之前已连续出现≥3根阳胜柱（连续双向胜阴），则标注"阳盛"，按原著应反向操作（阳盛出），本卡is_signal仍为true但附加warning
- 注："≥3根"的计数阈值为【整理者分析，非权威来源】，原著仅定性表述"极盛则反向操作"，未给出具体连续根数阈值

is_signal = (C[t] > C[left_ying]) AND (V[t] > V[left_ying]) AND (left_ying 存在)

操作时点规定（原著明确）：
- 下降途中的阳胜不能进；只有企稳回升之后的阳胜才能进（清华大学出版社前言原文："下降途中的第一个阳胜，能进吗？不能！因为'位置决定性质'"）
- 本规格卡仅做信号判定，操作建议需结合position和趋势状态

单向胜（非信号，仅标注）：
- 仅价胜：C[t] > C[left_ying] AND V[t] <= V[left_ying] → 标注"单向胜（价胜量不胜），观望"
- 仅量胜：C[t] <= C[left_ying] AND V[t] > V[left_ying] → 标注"单向胜（量胜价不胜），观望"

原著原文："如果碰到'单向胜'的状况，最好还是'看一阵'，即观望。"（豆丁网《伏击涨停十八法》转载原著）

### 5. 边界情况

| 情况 | 处理方式 |
|---|---|
| 左侧无阴柱（上市以来全阳） | left_ying不存在，不判定 |
| 当日为阴线（C[t]<O[t]）但价量双胜左侧阴柱 | 仍判定为阳胜柱（阳胜柱不要求当日为阳线，只要求价量双胜左侧阴柱），但标注"当日为阴线" |
| 左侧阴柱为假阴真阳 | 仍按C[day]<O[day]判定为阴柱，参与遍历 |
| 停牌后首日 | 停牌日保留在遍历范围内 |
| 除权除息日 | 必须使用前复权数据 |
| 新股上市首日 | 无左侧数据，不判定 |
| 数据异常（负数、空值） | 该日无效，遍历时排除 |

### 1. 自然语言定义

阴胜柱是指当前柱的价柱和量柱双双胜过其左侧最近阳柱的形态。在阴柱场景下，"胜过"表达为：价柱低于左侧阳柱收盘价（下跌），量柱大于左侧阳柱成交量（放量）。原著原文："如果今天的量柱和价柱同时'双向胜阳'，才是'阴胜'。"（拾荒网《图解伏击涨停十八法》转载原著；道客巴巴转载）。十二字令中"阴胜出"即指阴胜柱出现时可考虑退出，原著强调"初阴胜阳可出"。[《伏击涨停》（修订升级版）第3章第二节，张得一著，清华大学出版社2020年版]

### 2. 输入数据

| 变量名 | 数据含义 | 数据类型 | 数据来源 |
|---|---|---|---|
| C[t] | 当日收盘价 | float | 日线行情 |

| V[t] | 当日成交量 | int | 日线行情 |
| C[left_yang] | 左侧最近阳柱的收盘价 | float | 日线行情（向左遍历） |
| V[left_yang] | 左侧最近阳柱的成交量 | int | 日线行情（向左遍历） |

### 3. 精确计算公式

左侧最近阳柱确定规则：
- 从T-1日向左遍历，取第一个满足 C[day] > O[day] 的交易日作为 left_yang
- 遍历仅使用T-1日及之前数据（零未来函数）

阴胜柱判定：
- 前置条件：当日T为阴线，即 C[t] < O[t]（避免下降途中的小反弹阳柱被误判为阴胜柱）
- 价胜（阴柱视角）：C[t] < C[left_yang]（当日收盘价低于左侧阳柱收盘价，严格小于）
- 量胜：V[t] > V[left_yang]（当日成交量大于左侧阳柱成交量，严格大于）
- 双向胜阳：前置条件 AND 价胜 AND 量胜

### 4. 判定条件（布尔表达式）

is_signal = (C[t] < O[t]) AND (C[t] < C[left_yang]) AND (V[t] > V[left_yang]) AND (left_yang 存在)

单向胜（非信号，仅标注）：
- 仅价胜：C[t] < C[left_yang] AND V[t] <= V[left_yang] → 标注"单向胜（价跌量不增），观望"
- 仅量胜：C[t] >= C[left_yang] AND V[t] > V[left_yang] → 标注"单向胜（量增价不跌），观望"

原著原文："如果碰到'单向胜'的状况，最好还是'看一阵'，即观望。"

| 左侧阳柱为假阳真阴 | 仍按C[day]>O[day]判定为阳柱，参与遍历 |

### 1. 自然语言定义

小倍阳是指低位出现的温和倍量阳柱。原著原文："只要今天的量柱比昨天的量柱高一倍左右（不要高出许多），阳柱就是'小倍阳'。"（豆丁网《伏击涨停十八法全集》转载原著）。十二字令中"小倍阳，大胆入"即指小倍阳出现时可大胆介入，但原著补充："第一个小倍阳往往是试探，第二个小倍阳多数是试攻，第三个小倍阳..."（清华大学出版社前言原文），且"特指'位置比第一个小倍阳升高的第二或第三个小倍阳'"（掌阅精选转载原著）。[《伏击涨停》（修订升级版）第3章第二节，张得一著，清华大学出版社2020年版]

注：原著对"小倍阳"的量能上下限未给出明确量化标准【未能核实】，原著仅说"高一倍左右（不要高出许多）"。本规格卡采用1.9 ≤ V[t]/V[t-1] ≤ 3.0（下限1.9与批次1倍量柱规格卡一致，保证小倍阳严格是倍量柱子集；上限3.0为整理者分析，非权威来源）。【刊误表核实说明】经联网核实，《伏击涨停》第1版刊误表（股海明灯论坛2015-05-31帖）确实存在，但其内容全部为文字/数字校对错误，不包含小倍阳量能范围的理论参数修正。上一版v1.1中"刊误表修正为1.8-3.0最佳2.0"的表述系未验证信息，本版已回退。

### 2. 输入数据

| 变量名 | 数据含义 | 数据类型 | 数据来源 |
|---|---|---|---|
| C[t] | 当日收盘价 | float | 日线行情 |
| O[t] | 当日开盘价 | float | 日线行情 |
| V[t] | 当日成交量 | int | 日线行情 |
| V[t-1] | 前一日成交量 | int | 日线行情 |
| C[t-1] | 前一日收盘价 | float | 日线行情 |
| HHV_250 | 近250日最高价 | float | 日线行情（位置判定） |
| LLV_250 | 近250日最低价 | float | 日线行情（位置判定） |

### 3. 精确计算公式

量能条件（原著未给出明确量化上下限【未能核实】，本规格卡采用整理者分析值）：
- volume_ratio = V[t] / V[t-1]
- 1.9 ≤ volume_ratio ≤ 3.0
- 下限1.9与批次1倍量柱规格卡一致，保证小倍阳严格是倍量柱子集
- 上限3.0为整理者分析，非权威来源

价格条件：
- C[t] > C[t-1]（阳柱，收盘价高于昨收）
- C[t] > O[t]（当日为阳线实体）

位置条件：
- position_pct = (C[t] - LLV_250) / (HHV_250 - LLV_250) × 100%
- position = "low" 当 position_pct < 30

小倍阳序号（原著明确）：
- xiaobeiyang_seq：从T日向左遍历，统计连续小倍阳的序号
- 1=试探，2=试攻，3=主攻
- 原著："第一个小倍阳往往是试探，第二个多数是试攻，第三个..."（清华大学出版社前言原文）
- 操作时点：第一个介入不够好；第二个较好；第三个最好（原著明确）

### 4. 判定条件（布尔表达式）

is_signal = (1.9 ≤ V[t]/V[t-1] ≤ 3.0) AND (C[t] > C[t-1]) AND (C[t] > O[t]) AND (position = "low")

与倍量柱的区别：
- 倍量柱（批次1规格卡3）：V[t]/V[t-1] ≥ 1.9，无上限，无位置限制
- 小倍阳（本卡）：1.9 ≤ V[t]/V[t-1] ≤ 3.0（下限与倍量柱一致，上限3.0为整理者分析），且 position=low

### 5. 边界情况

| 情况 | 处理方式 |
|---|---|
| volume_ratio > 3.0（超出小倍阳上限） | 不判定为小倍阳，标注"超出小倍阳上限3.0（整理者分析阈值）" |
| volume_ratio < 1.9 | 不判定为倍量柱，更不判定为小倍阳（低于批次1倍量柱下限1.9） |
| V[t-1] == 0（停牌后首日） | 分母为0，不判定，标注"前一日无量" |
| 当日为假阳真阴 | 排除（C[t]<C[t-1]，非真阳） |
| 位置为mid/high | 不判定为小倍阳（本卡限定低位），但可标注"非低位小倍阳" |
| 除权除息日 | 必须使用前复权数据 |
| 新股上市首日 | 无250日位置数据，position=unknown，不判定 |
| 数据异常（负数、空值） | 该日无效 |
